## Ⅰ 反串（第十五卷第五章）

A：<small>原文</small>

```

欧洲人把美洲人灭绝之后，不得不把非洲人当奴隶，为的是开垦这许多土地。

如果不使用奴隶种植制糖作物，糖价就会太高。

这些人从脚黑到头，鼻子扁得令人难以怜悯。

我们无法想象，睿智的上帝竟然会把一个灵魂，而且是一个优秀的灵魂，放到一个黝黑的躯体中去。

把肤色视为人的本质要素，这是很自然的。使用太监的亚洲人总是特别强调黑人与我们没有任何关系。

从头发的颜色可以判断皮肤的颜色。埃及人是世界上最优秀的哲学家，他们非常看重头发的颜色，凡是长着红头发的人，只要落入他们手中，就统统杀掉。

文明民族把黄金视为珍品，而在黑人看来，金项链不如玻璃项链珍贵，这就是黑人缺乏常识的一个明证。

我们不可能把黑人视为人，假如我们把他们视为人，那么，我们就要怀疑自己是不是基督徒了。

心胸狭隘的人夸大了我们对待黑人的不公正。因为，倘若果真如此，彼此缔结了那么多的条约的欧洲君王们，难道就不能缔结一个促进慈善和怜悯的一般性条约吗？

```

B：<small>我的回应</small>

1. 孟德斯鸠在这段里戴上了辩护者的面具。他没有直接说“奴隶制是错的”，而是假扮成奴隶制的支持者。
2. 他把所有为奴隶制辩护的论点一条一条摆出来——经济成本、外貌差异、上帝意志、文明等级、历史先例。每一条都是当时真实存在的论调，但他没有反驳任何一条，只是陈列。
3. 其中最致命的一句是：“我们无法想象，睿智的上帝竟然会把一个灵魂，而且是一个优秀的灵魂，放到一个黝黑的躯体中去。”
4. 这句话暴露了整个奴隶制辩护的荒谬：辩护者自以为能判断上帝的意志——他们知道上帝会把灵魂放在哪里，也知道不会放在哪里。他们在用一个无法验证的前提去支撑一个可以被经验推翻的结论。
5. 他在这里做的是反串。他不是在表达观点，他是在把对方的逻辑推到极致，推到连对方自己都不好意思承认的地步。


## Ⅱ 自愿为奴（第十五卷第五章）

A：<small>原文</small>

```

现在是探求奴役权的真正起源的时候了。奴役权应该是创建在事物性质的基础之上的，让我们看一下，奴役权是不是来自某些情况。

在所有专制政体下，卖身为奴很容易，那里的政治奴役制在一定程度上扼杀了公民自由。

佩里先生说，俄国人出卖自己很方便。我知道这是为什么，因为他们的自由毫无价值。

在亚齐，人人都设法卖身为奴，一些大贵族的奴隶不下千人，这些奴隶都是大商人，他们也有许多奴隶，他们的奴隶又有许多奴隶。奴隶可以被继承，也可以买卖。那些国家里的自由民因过于软弱而无力反抗政府，于是就设法成为那些施行暴政者的奴隶。

这就是某些国家中温和奴役权的合理起源。它理应温和，因为它创建在一个人为发挥自己的作用而自由选择主人的基础上，因而在双方当事人之间形成契约关系。

```

B：<small>我的回应</small>

1. 孟德斯鸠在这里区分了强制奴役和自愿为奴。但问题在于：这个区分不改变事情的本质。
2. 无论是被迫卖身，还是“自愿”卖身，结果都是一样的——人变成了财产，可以被买卖、被继承、被转让。契约的形式并没有改变奴隶制本身的内容。
3. 他这么做的原因很清楚：他真正维护的不是奴隶制本身，而是他所崇拜的古典秩序——古希腊、古罗马的奴隶制是它们制度运作的基础。
4. 他可以在理论上否定种族奴隶制的根基，但一旦轮到他想维护的那个文明体系，他的立场就变得暧昧了。
5. 他试图为奴役权找到一个“合理”的根基，但这个根基的前提本身就已经不合理了。


## Ⅲ 气候奴隶制（第十五卷第五章）

A：<small>原文</small>

```

下面是奴役权的另一个起源，它甚至是人间最残酷的奴役权的起源。

有些国家的酷热气候使人身体疲惫，精神委靡，只有借助惩罚才能让人履行艰苦的义务。在这些地方，奴隶制对理性的冲击相对小些。由于奴隶主懒待君主，奴隶也就懒待主子。那里的民事奴隶制与政治奴隶制并存。

亚里士多德试图证明，有些奴隶与生俱来就该当奴隶，可是他的阐述不能证明此说不误。我想，如果确有与生俱来的奴隶，那就是我刚才说到的那些奴隶。

然而，人人生而平等，所以应该说，奴隶制是反自然的，尽管有些国家的奴隶制创建在自然理性的基础之上。必须把这些国家与连自然理性都唾弃奴隶制的国家严格区分开来，例如早已成功地废除了奴隶制的欧洲国家。

普鲁塔克在《努玛传》中写道，在沙特恩时代，既没有主人，也没有奴隶。在我们欧洲的气候下，基督教让我们回归到那个时代。

```

B：<small>我的回应</small>

1. 孟德斯鸠在这一段里做了一件事：他把气候分析从描述工具变成了辩护工具。
2. 他关于炎热气候影响人的体力与精神状态的观察本身是对的——这和他在第三卷里的气候分析是一致的。身体在炎热环境下容易疲惫，这没有问题。
3. 但问题在于他把这个观察延伸到了奴隶制上。他的逻辑是：因为炎热气候让人精神委靡，所以需要惩罚才能让人劳动，所以在这些地方，奴隶制“对理性的冲击相对小些”——甚至“创建在自然理性的基础之上”。
4. 这是一个跳跃。气候可以解释为什么某些地方的劳动方式不同，但气候不能为奴隶制提供合法性。他在第一卷里说“法是源于事物本性的必然关系”，在这里他试图把奴隶制也说成是“源于事物本性”的。
5. 他真正想维护的，是希腊罗马的古典秩序。他愿意用气候来解释奴隶制，是因为这个解释可以让奴隶制看起来不是暴力的产物，而是自然的产物。
6. 这个观点不是全错的——气候确实影响人。但他把这个观点用错了地方。气候可以用来解释差异，不能用来论证压迫。


## Ⅳ 自由民与矿山（第十五卷第五章）

A：<small>原文</small>

```

所以，必须把基于自然原因的奴隶制限制在某些国家的范围内，我觉得，在所有其他国家中，无论社会所要求的劳动如何艰苦，任何工作都应该由自由民去完成。

我之所以这样想，是因为基督教在欧洲废除民事奴隶制之前，矿山劳动被认为是极端艰辛的，只能驱使奴隶或罪犯去干。可是，如今大家已经知道，矿山的雇工们生活很幸福。微小的特殊待遇对从事这种职业起到了鼓励作用，收入随劳动的增加而增加，矿工们因而热爱自己的工作胜过他们所能找到的其他任何工作。

只要是理性而不是贪婪支配劳动，那就绝对不会有任何艰苦到人的体力无法支撑的劳动。由于工艺发明或应用的机器带来了方便，在别处驱使奴隶从事的劳动，在我们这里可以利用机器来完成。土耳其的蒂米什瓦尔总督管区中的矿藏比匈牙利丰富，产量却比匈牙利少，原因就是土耳其人从来就只知道使用奴隶进行开采。

我不知道我的这个观点是出自我的精神还是心灵。世界上或许没有一个地方的气候会让自由人无法参加劳动。法律制定得不好，于是有了懒人，有了懒人，于是就让他们当奴隶。

```

B：<small>我的回应</small>

1. 孟德斯鸠这段文字的逻辑本身没有毛病。他论证了两点：自由民愿意干艰苦的活，只要收入合理；机器可以替代奴隶劳动。
2. 他用匈牙利和土耳其的矿山做对比——土耳其用奴隶，产量反而低——来说明奴隶制不但不必要，甚至效率更差。
3. 这些观察是对的。问题在于他仍然在试图为奴隶制找一个“合理范围”。他说的“把基于自然原因的奴隶制限制在某些国家”本身就是在用逻辑为不合理的事情找位置。
4. 这里要明确一点：奴隶制不正义，不是因为效率低，不是因为气候不需要它，不是因为可以用机器替代。它不对，是因为它把人当财产。
5. 孟德斯鸠在这段话里没有处理这个层面。他讨论的是“奴隶制有没有用”，而不是“奴隶制对不对”。他前进了一步——承认自由民能胜任艰苦劳动，承认机器可以替代奴隶——但他没有跨出他给自己划定的边界。


## Ⅴ 奴隶制的喧嚣（第十五卷第五章）

A：<small>原文</small>

```

每天都有人在说，我们要是有奴隶，那该多好。

可是，想要作出正确判断，不应审视奴隶对每个民族中骄奢淫逸的少数富人是否有用，毫无疑问，奴隶对他们肯定有用。

可是，从另外一个观点来看，在这个国家中如果以抽签决定，哪些人应该做自由民，哪些人应该做奴隶，我相信，这些富人谁也不愿意这么做。鼓吹奴隶制最卖力的人大概最害怕，最贫苦的人也会很害怕。

所以说，鼓吹奴隶制的喧嚣其实就是骄奢淫逸的喧嚣，而不是关爱公共福祉的呼声。

人人都喜欢成为他人的财产、荣誉和生活的主人，人人想到此处都会无比激动，这难道有什么怀疑吗？在这些事情上，如果想要知道每个人的愿望是否正当，那就让我们对每个人的愿望作一番审视。

```

B：<small>我的回应</small>

1. 这一段他终于正常了。前几段他还在替奴隶制找理由：气候、契约、效率、劳动强度。这一段他换了个视角。
2. 他不再讨论“奴隶制合不合理”，而是直接问：“鼓吹奴隶制的人到底想要什么？”
3. 他的回答是：他们要的不是公共福祉，是自己的好处。“人人都喜欢成为他人的财产、荣誉和生活的主人”——这句话已经直接指向了问题的根源。
4. 如果拿抽签决定谁做奴隶谁做自由民，那些喊得最响的人第一个不敢玩。
5. 能写出这一段，说明他其实知道奴隶制的根源在哪。不在气候，不在经济，在于人的欲望。他前几段只是在替自己认同的东西找补，这一段他回到了自己的观察力上。


## Ⅵ 属物奴隶与属人奴隶（第十五卷第五章）

A：<small>原文</small>

```

奴役有两种，一种是属物奴役，一种是属人奴役。

属物奴役把奴隶捆绑在土地上，塔西佗记述的日耳曼人的奴隶就是这种生产奴隶，这种奴隶不在主人家中服役，只向主人缴纳一定数量的谷物、牲畜或织物，使用此类奴隶的目的仅此而已。匈牙利、波希米亚和德意志南部一带也有这种奴隶。

属人奴役就是让奴隶从事家务劳动，主要与主人家的人有关。

兼有属物和属人两种性质的奴役，是对奴役的极度滥用。斯巴达对希洛奴隶的使用就是这种性质的奴役。户外的所有劳作都由这些奴隶承担，在家里还要遭到各种各样的侮辱，所以说，希洛奴隶是违背事物性质的奴役。

俭朴的平民只有一个属物奴隶，因为妻子儿女都参与家务劳动。奢华的平民拥有属人奴隶，因为奢华需要奴隶从事家务劳动。希洛奴隶则让同一个人兼做奢华人家的属人奴隶和俭朴人家的属物奴隶。

```

B：<small>我的回应</small>

1. 孟德斯鸠在这里对奴隶制做了一次分类。他将奴隶分为绑在土地上的（属物）和绑在主人身上的（属人），并指出斯巴达那种两种兼有的形式是“极度滥用”。
2. 这个分类本身是准确的。确实存在不同形式的奴隶制——有的更接近农奴，有的更接近家奴，有的两者兼具。他注意到这些差异，并且愿意把斯巴达那种单独拎出来批评。
3. 但他仍然没有追问那个根本问题。他在区分“好一点的奴隶制”和“坏一点的奴隶制”，却始终没有跨出一步说：“不管哪种，都不对。”
4. 他能看见斯巴达的希洛制比日耳曼的农奴制更恶劣，但他没有往前走。这一段可以放过：分类是对的，但他还是没有追问到底。


## Ⅶ 法律与奴隶制（第十五卷第五章）

A：<small>原文</small>

```

但是，无论什么性质的奴隶制度，公民法都应该做两件事，一方面取消对奴隶制的滥用，另一方面防止奴隶制的危险。

```

B：<small>我的回应</small>

1. 这段话从法律角度来看，是对的。限制虐待、防止危险，确实是法律该做的事。
2. 但他还是没有说出那句话。他说的是“怎么管好奴隶制”，而不是“奴隶制本身要不要被废除”。
3. 他已经在承认奴隶制存在的前提下讨论法律了，但那个更根本的问题——人能不能成为财产——他始终没有正面回应。
4. 他说的都对。但他就是不说那句最重要的话。


## Ⅷ 女奴与贞操（第十五卷第五章）

A：<small>原文</small>

```

在伊斯兰国家里，主人不仅主宰女奴的生命和财产，就连女奴的所谓品德和操守，都得听任主人摆布。

这些国家的不幸之一是，大部分人生来不为别的，就为他人的奢华服务。这种奴役得到的回报，就是听凭奴隶们享有的懒惰。对于国家来说，这是一个新的不幸。

对于那些被幽禁的人来说，这种懒惰使得东方的后宫变成了乐园，那些生怕劳动的人能在安静的后宫里找到他们的幸福。但是，我们却由此看到，这有悖创建奴隶制的初衷。

依据理性的要求，主人的权力不得超出奴隶应当提供的服务范围。奴隶制是为有用而建，不是为淫逸而建。保护贞操的法律属于自然法，应为世界各国所周知。

保护奴隶贞操的法律，如果说，在凭借权力可以毫无约束地玩弄一切的国家里是好的，那么，在君主政体国家里岂不是更好吗？在共和政体国家里岂不是更好吗？

伦巴第法的一条规定似乎应该适用于所有政体，“主人如果糟蹋奴隶的妻子，奴隶夫妻二人就可一起获得自由民身份。”这是既可防止主人淫乱，又不失之过严的令人赞叹的折中之法。

我不曾发现罗马人在这方面有何良法。他们听任主人淫乱无度，甚至在某种程度上剥夺奴隶结婚的权利。奴隶是国民中最卑微的人群，可是，无论卑微到什么程度，他们也需要懂得廉耻。何况，剥夺奴隶的婚配权，也就损害了公民的婚配权。

```

B：<small>我的回应</small>

1. 孟德斯鸠这段话说的是：主人不应该让奴隶做超出服务范围的事，尤其不能把奴隶的身体当私产随意使用。他引用伦巴第法作为正面例子，批评罗马法在这方面做得不够好。
2. 这逻辑上是对的。主人不应该糟蹋奴隶的妻子，奴隶也应该有婚姻权，这些判断本身没问题。
3. 他还在这一段前进了一步：他承认“无论卑微到什么程度，奴隶也需要懂得廉耻”。这句话意味着他至少承认奴隶是有尊严的，不是一个纯粹的工具。
4. 但他还是没有说出那句话。他在谈“主人不应该做什么”，在谈“法律应该保护奴隶的贞操”，在谈“哪些政体下保护得更好”——但他始终没有面对那个根本问题：一个人有没有权利拥有另一个人的身体。
5. 他能走到“奴隶也有廉耻”这一步，已经比前面几段进了一步。但他还是没有迈过那道坎。


## Ⅸ 奴隶制在不同政体下的后果（第十五卷第五章）

A：<small>原文</small>

```

在不同政体下，奴隶数量众多的后果各不相同。在专制政体下，奴隶多根本不构成负担，因为在国家机体内实行的就是政治奴隶制，所以，人们几乎感受不到民事奴隶制的存在，所谓自由民享有的自由并不比没有这个称谓的人多。这些非自由民以太监、释奴和奴隶的身份几乎控制着一切事务，自由民与奴隶的地位差异极小。所以在专制政体下，奴隶多寡无关紧要。

不过，在政体宽和的国家里，奴隶不能太多却事关重大。政治自由使得公民自由极为珍贵，被剥夺公民自由的人也就失去了政治自由；他眼睁睁看着全社会的人幸福地生活着，而他却不是这个社会的成员，他觉得，安全保障不是为他而是为别人确立的；他看到，主人的心灵日甚一日地升华，而他自己的心灵却越来越卑微。看着别人享受自由而自己却不能，从而令人最深切地感到自己的地位已与牲畜相去不远。这种人是社会的天敌，他们若是人数众多，那就很危险。

在宽和政体下，国家被奴隶的反叛弄得焦头烂额，而这种情况在专制政体下却极为罕见。

```

B：<small>我的回应</small>

1. 这一段孟德斯鸠看准了。他看清了奴隶制真正危险的原因：不在于奴隶人数多少，而在于奴隶能不能看到别人享有自由而自己没有。
2. 在专制政体下，人人都不自由，奴隶反而不觉得自己被剥夺了什么。但在宽和政体下，自由是可见的、被珍视的，奴隶每天都能看到别人享受自由而自己不能，这种对比本身就是最强烈的压迫感。
3. 他描述的那种“看着别人幸福而自己不是社会成员”的状态，才是奴隶制真正危险的地方。反叛不是来自最被压榨的人，而是来自已经看见自由但不能获得的人。
4. 他这一段观察到位了。


## Ⅹ 武装奴隶（第十五卷第五章）

A：<small>原文</small>

```

把奴隶武装起来，对于共和政体的危险甚于君主政体。在君主政体下，尚武的人民和贵族集团能够有效地控制武装的奴隶。在共和政体下，手持武器的奴隶与公民处于平等地位，所以仅仅具有公民身份的人很难控制武装的奴隶。

哥特人征服西班牙人后分散在全国各地，很快就变得虚弱不堪。他们在法规方面做了三件重要的事：废除了禁止与罗马人通婚的旧习；规定借助国家财政获得解放的奴隶在战时必须服役，违者将处以奴役；每个哥特人参战时必须携带自己十分之一的奴隶，并为他们配置武器装备。与留下的奴隶相比，十分之一是一个微不足道的数目。这些被主人带上战场的奴隶并不单独组队，而是就在军中，从某种意义上说，就像在家里一样。

```

B：<small>我的回应</small>

1. 这一段的分析是对的。孟德斯鸠没有在谈“奴隶制对不对”，他在谈“武装奴隶在不同政体下的风险差异”。
2. 哥特人的做法很聪明：让奴隶随主人上战场，但不单独成军。奴隶没有独立建制，就不会形成自己的政治力量。
3. 这是制度设计的精确分析，没什么问题，直接肯定。


## Ⅺ 全民尚武与武装奴隶（第十五卷第五章）

A：<small>原文</small>

```

如果全体国民都是战士，武装的奴隶更没有什么可怕了。

按照日耳曼法，奴隶如果偷窃存放在某处的东西，将受到与自由民一样的惩罚；可是，如果以暴力抢夺，他将要受到的惩罚只是把抢来的东西归还原主而已。对于日耳曼人来说，凡是基于勇气和力量的行为，都不令人鄙夷。他们在战争中使用奴隶。

在大多数共和国里，人们总是试图挫灭奴隶的勇气，自信心十足的日耳曼人想的却是增强奴隶的胆魄，日耳曼人的武器须臾不离身，所以一点儿也不怕武装的奴隶，相反，奴隶是他们进行掠夺和获取战功的工具。

```

B：<small>我的回应</small>

1. 这一段和上一段是同一个逻辑：武装奴隶是否危险，不取决于奴隶本身，而取决于统治者的组织能力。
2. 日耳曼人全民皆兵，武器不离身，自信能掌控局面，所以不但不怕武装奴隶，反而把奴隶当作获取战功的工具。
3. 他们对偷窃和抢夺的惩罚差异也反映了同样的尚武倾向——基于勇气和力量的行为不被鄙夷。
4. 这段分析是透彻的，直接肯定。


## Ⅻ 宽和与严酷（第十五卷第五章）

A：<small>原文</small>

```

在政治宽和的国家里，奴隶众多会令人担心出现危险，不过，只要给予奴隶人道待遇，就可防止这种危险。只要主人不比奴役本身更狠心，人们对一切都能习惯，甚至对奴役也能习以为常。雅典人对奴隶十分宽和，所以，斯巴达被奴隶搅得天翻地覆，雅典却平安无事。

我们看到，最初的罗马人并未为奴隶而感到不安。只是当罗马人对奴隶丧失了所有人道感情之后，才发生了可与布匿战争相比的内战。

自己从事劳动的人民对待奴隶，通常比自己不从事劳动的人民要宽厚些。最初的罗马人与奴隶同生活，同劳动，同饮食，他们对待奴隶很宽厚，很公正。他们对奴隶的最严厉惩罚，不过就是让奴隶背负一根木叉从邻居们的面前走过。道德风尚足以维持奴隶的忠诚，无须求助于法律。

可是，当罗马人强大之后，当奴隶变成了他们奢华和傲慢的工具，而不再是他们的伙伴时，由于道德风尚已经沦丧，所以就得求助于法律，甚至是十分严苛的法律，否则，主人的安全就难以确保。这些残酷的主人生活在奴隶中间，如同生活在敌人中间一样。

于是制定了西拉里亚诺元老院法令和其他一些法律，这些法律规定，若有一个主人被杀，居住在主人家的所有奴隶，以及附近所有能听到呼救声的奴隶，一律处死。在这种情况下，凡出于救助目的而藏匿嫌犯者，则以谋杀罪论处。奴隶即使奉主人之命将其杀死，依然有罪；没有阻止主人自杀的奴隶也将受到惩罚。主人若在旅途中遇害，陪同他的奴隶和逃走的奴隶都将被处死。即使已被证实清白无辜，涉案奴隶依然要受这些法律的惩处；其目的在于迫使奴隶极度敬重自己的主人。

这些法律并不表明民事管理有这种需要，而是由于民事管理中存在着弊病和不完善之处。它们违背公民法原则，因而绝非源自公民法的公正。它们赖以确立的是战争原则，有所不同的一点是敌人存在于内部。西拉里亚诺元老院法令源自万民法的一项原则，那就是一个社会即使不完善也应自保。

当官吏们不得不制定此类残酷的法律时，情况肯定已经很糟糕了，因为，那时要让奴隶服从已非易事，因而不得不对不服从者施以重罚，或是怀疑他们的忠诚。一个优秀的立法者能够防止自己变成一个可怕的立法者。因为，若要罗马人的奴隶信任法律，除非法律信任奴隶。

```

B：<small>我的回应</small>

1. 这一段也完全站得住。他用雅典和斯巴达、早期罗马和后期罗马做了两组对比，论证了一个简单的道理：宽和对待奴隶，奴隶反而不容易成为敌人；严酷对待奴隶，主人就不得不生活在敌人中间。
2. 西拉里亚诺元老院法令就是这种恐惧的产物——它把奴隶当成潜在的敌人来防范，用集体处决来强迫奴隶“敬重”主人。
3. 他的观察是准确的，逻辑是连贯的。这段分析本身没有问题。
