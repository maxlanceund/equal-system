## I. 摘要

本文在前两篇论文的基础上，提出**信息投影框架**——一个用以量化宏观描述的信息损失的信息论框架。

前两篇论文论证了：复合投影 g ∘ f: Ω → M′ 的非单射性，导致宏观描述不完整。但这一结论是定性的。

**本文的核心贡献是八个：**

**第一，定义信息损失率 D_f。** D_f = H(Ω|M′) / H(Ω)，取值范围 [0,1]。

**第二，将逆推误差下界严格归约到率失真理论。** 对一般失真度量 d，逆推误差下界由率失真函数给出：ε(h) ≥ R⁻¹(I(Ω; M′))。

**第三，给出信息损失率的完整标度理论。** 通过四组数值模拟（离散精确、帐篷映射混沌、连续固定分辨率、连续动态分辨率），提炼出统一公式 D_f → α（其中 Δ ~ σ^α），并给出有限尺寸修正公式与显式收敛条件。

**第四，用真实物理系统验证框架。** 用 L=32 的 2D Ising 模型进行 Monte Carlo 模拟，发现 D_f 在临界温度 Tc = 2.269 附近取最小值。

**第五，讨论 D_f 对 Ω 定义的敏感性。** 在物理学中，Ω 是本体论确定的；在经济学中，Ω 是理论构造的。

**第六，明确区分"信息投影框架"与"计量经济学识别理论"。**

**第七，给出显式收敛条件。** 当 log₂σ > 3·log₂Δ₀/α 时，D_f 与 α 的偏差小于 10%。

**第八，时间反演对称性测试。** 通过谐振子系统的数值模拟，发现 D_f 在无摩擦（可逆）动力学下**时间对称**。**D_f 本身不捕捉时间箭头。** 时间箭头需要耗散（不可逆动力学）。这是一个负面结果。

**本文的定位**：本文不是操作手册，不告诉实证研究者"怎么做"。本文是一篇科学哲学论文，提出一个框架，告诉理论研究者"为什么某些做法在结构上不可能"。

## III. 信息损失率：定义与性质

### 1. 基本设定

- Ω：微观状态空间（有限或连续），带有概率测度 p。
- M′：粗粒化宏观状态空间。
- g ∘ f: Ω → M′：复合投影，非单射。

### 2. 定义

**定义 1（信息损失率）**：

D_f = H(Ω | M') / H(Ω)

**定义 2（信息保留率）**：

R_f = 1 - D_f = I(Ω; M') / H(Ω)

### 3. 基本性质

**性质 1（取值范围）**：0 ≤ D_f ≤ 1。

**性质 2（单射情形）**：若 g ∘ f 是单射，则 D_f = 0。

**性质 3（完全丢失情形）**：若 Ω 与 M′ 独立，则 D_f = 1。

**性质 4（结构依赖性）**：D_f 的**定义**只依赖于 (Ω, M′, g ∘ f, p)，不依赖于样本大小、计算能力或模型复杂度。

**性质 5（时间反演中性）**：D_f 是一个**静态**量。它的定义不涉及时间演化。因此，D_f 本身不携带时间箭头信息。时间不对称性必须来自动力学，而非来自 D_f 的定义。

## IV. 率失真理论与逆推误差下界

### 1. 率失真函数

**定义 3（率失真函数）**：

R(D) = min_{q(y|x): E[d(X,Y)] ≤ D} I(X; Y)

### 2. 逆推误差下界定理

**定理 1（率失真下界）**：

设逆推映射 h: M′ → Ω，逆推误差 ε(h) = E[d(X, h(M′))]。则：

ε(h) ≥ R⁻¹(I(Ω; M'))

**证明**：见附录 A。

**推论 1**：ε(h) ≥ R⁻¹(H(Ω)(1 - D_f))。

**推论 2（数据量无关性）**：R⁻¹(I(Ω; M′)) 只依赖于 Ω、M′、p 和 d，不依赖于样本大小。**但这一结论的前提是 Ω 固定。**

用帐篷映射 T(x) = 1 - |2x - 1|，其 KS 熵精确等于 log₂2 = 1 比特/步。设 N_micro = 10000 个初始点，均匀分布在 [0, 0.001]，宏观格子数 M = 16。

**结论**：粗粒化熵以 ≈ 1 比特/步增长，与帐篷映射的 KS 熵一致。饱和到 log₂16 = 4 比特。

### 6.3 连续情形（固定分辨率）

一维扩散，σ₀ = 1，D = 10，Δ = 10。高斯微分熵 h_micro = (1/2) log₂(2πeσ²)。

| 10000 | 447.215 | 10.852 | 7.530 | 0.3061 |

**结论**：连续情形 D_f 缓慢趋近 0，与离散情形方向相反。

### 6.4 连续情形（动态分辨率）与统一标度律

设 Δ ~ σ^α，数值结果（σ = 447 时）：

| α | D_f | 渐近值 | 差距 |
| :--- | :--- | :--- | :--- |
| 0.00 | 0.3061 | 0 | 0.31 |
| 0.25 | 0.5090 | 0.25 | 0.26 |
| 0.50 | 0.7118 | 0.50 | 0.21 |
| 0.75 | 0.9146 | 0.75 | 0.16 |
| 1.00 | 1.0000 | 1.00 | 0.00 |

**渐近结果**：当 σ → ∞ 时，D_f → α。

**推导**（见附录 B）：

D_f(σ; α) = [log₂Δ₀ + α log₂(σ/σ₀)] / [log₂(σ/σ₀) + log₂(σ₀√(2πe))]

**有限尺寸修正与显式收敛条件**：

当 log₂σ > 3·log₂Δ₀/α 时，|D_f - α| < 0.1·α。

**统一分类**：

| 情形 | 标度关系 | D_f 极限 | 收敛条件 |
| :--- | :--- | :--- | :--- |
| 离散（自旋） | N 增大 | 1 | N > 1000 |
| 连续 + 固定 Δ | Δ = const | 0 | log₂σ >> 3.32 |
| 连续 + Δ ~ σ^α | 0 < α < 1 | α | log₂σ > 3·log₂Δ₀/α |
| 连续 + Δ ~ σ | α = 1 | 1 | 立即 |

**结论**：信息损失率的极限值，不取决于"非单射性"本身，而取决于微观熵与宏观熵的相对标度关系。

### 6.5 离散情形与连续标度律的关系

离散情形不能简单地视为 α_eff → 1 的特例。离散情形的微观熵 H(Ω) = N 是**线性**增长的，而连续情形的 h_micro = (1/2)log₂(2πeσ²) 是**对数**增长的。两者在数学上不同。

**因此，离散情形和连续标度律是两个独立的结果，不能强行统一。**

## VII. 真实系统验证：2D Ising 模型的临界行为

### 7.1 模型与设定

- 晶格尺寸：L = 32（1024 个自旋）
- 更新算法：Metropolis Monte Carlo
- 温度范围：T ∈ [0.5, 10.0]，含临界温度 Tc = 2.269

**D_f 在 T = 2.5 取最小值 0.991648，紧邻临界温度 Tc = 2.269。**

### 7.4 物理解释

临界点附近，关联长度发散，磁化涨落最大，宏观态分布最宽，H(M) 最大，因此 D_f 最小。

### 7.5 采样不足的说明

理论上限 H(M) = log₂(2L²+1) ≈ 11.0 比特。实测最大 H(M) = 8.55。D_f 被系统性高估，但趋势仍有效。

## VIII. 时间反演对称性测试：一个负面结果

### 8.1 问题

D_f 能不能区分时间的正向和逆向？

### 8.2 模型

一维谐振子系统，N = 2000 个粒子，初始分布为窄高斯。

### 8.3 结果

| 情形 | 平均误差 | 最大误差 |
| :--- | :--- | :--- |
| 无摩擦 | **0.000003** | 0.000026 |
| 有摩擦 γ=0.1 | 0.000023 | 0.000129 |
| 有摩擦 γ=0.5 | 0.000047 | 0.000204 |

### 8.4 结论

**D_f 在无摩擦（可逆）动力学下时间对称。**

- 误差 3×10⁻⁶，是浮点精度级别
- **非单射投影本身不产生时间箭头**
- **时间箭头需要耗散（不可逆动力学）**

### 8.5 这个结果推翻了什么

**推翻的**：一个**更强的、非本文原有的**命题——"非单射投影本身产生时间箭头"。

**没有推翻的**：信息投影框架的核心命题——"不可逆推是结构性的、静态的"。

**两者的区别**：

- "不可逆推"是**认识论**命题
- "产生时间箭头"是**动力学**命题

**本文从未声称后者。**

### 8.6 意义

这是一个负面结果。它排除了一个可能性，但没有产生新东西。它的价值在：

1. 澄清了"静态来源"和"动力学来源"的区别
2. 说明 D_f 是一个时间反演中性的量
3. 为后续研究指明了方向：时间箭头必须从动力学中寻找

## XI. Ω 的本体论不对称及其后果

### 1. 不对称的陈述

- **物理学**：Ω 是本体论上确定的。
- **经济学**：Ω 是理论构造的。

### 2. 不对称的后果

**后果一**：D_f 的认识论地位不同。

**后果二**：D_f 的比较范围不同。

### 3. "局部数学类比"的精确定义

**定义（局部数学类比）**：两个领域 A 和 B 在问题 P 上构成局部数学类比，当且仅当：

1. A 和 B 都可以用同一组数学对象 (Ω, M′, g ∘ f, p, d) 来建模。
2. A 和 B 中的 D_f 和 ε_min 满足同一组定理。
3. A 和 B 的 Ω 之间**不要求**存在双射。
4. A 和 B 的 Ω **不要求**满足同一组公理。

### 3. 局限二：概率测度 p 的选择

### 4. 局限三：连续情形

本文的定理在有限集上严格成立。

### 5. 局限四：率失真函数的计算

## XIV. 结论

信息投影框架的核心结果是八个：

**第一，定义信息损失率 D_f。**

**第二，将逆推误差下界严格归约到率失真理论。**

**第三，给出信息损失率的完整标度理论。**

**第四，用 2D Ising 模型验证真实系统。**

**第五，讨论 D_f 对 Ω 定义的敏感性。**

**第六，明确区分信息投影框架与识别理论。**

**第七，给出显式收敛条件。**

**第八，报告一个负面结果：D_f 不捕捉时间箭头。** 时间反演对称性测试显示，D_f 在可逆动力学下时间对称。非单射投影本身不产生时间箭头，时间箭头需要耗散。

**本文的最终定位**：

> 本文不是一篇操作手册，而是一篇科学哲学论文，提出信息投影框架。D_f 是一个概念工具，它揭示了不可识别性的结构性来源。标度律 D_f → α 是信息投影框架最重要的定量结果。时间反演对称性测试是一个负面结果，它澄清了静态信息丢失与动力学不可逆性的区别。

**信息投影框架的结论是**：不可识别性有一个比"数据不够"更深层的结构性来源——宏观描述的非单射性。这个来源不会随着数据量增加、计算能力提升、模型复杂化而消失。**但非单射性本身不产生时间箭头。**

## 附录 A：定理 1 的证明

**证明**：

**步骤一（马尔可夫链）**：由于 h 是确定性映射，Ω → M′ → h(M′) 构成马尔可夫链。

**步骤二（数据处理不等式）**：

I(Ω; h(M')) ≤ I(Ω; M')

**步骤三（率失真函数的定义）**：任何恢复信道 q 若满足 E[d(X,Y)] ≤ ε，则必须有 I(X;Y) ≥ R(ε)。因此：

R(ε(h)) ≤ I(Ω; h(M')) ≤ I(Ω; M')

**步骤四（逆函数）**：由于 R 严格递减：

ε(h) ≥ R⁻¹(I(Ω; M'))

证毕。

## 附录 B：标度律推导

设 h_micro = (1/2) log₂(2πeσ²) = log₂σ + C₀，其中 C₀ = (1/2)log₂(2πe) ≈ 2.047。

设 Δ = Δ₀ · (σ/σ₀)^α，则 log₂Δ = log₂Δ₀ + α log₂(σ/σ₀)。

当 σ >> Δ 时：

D_f = log₂Δ / h_micro = [log₂Δ₀ + α log₂(σ/σ₀)] / [log₂(σ/σ₀) + log₂σ₀ + C₀]

当 σ → ∞ 时：D_f → α

**收敛条件推导**：

要求 |D_f - α| < 0.1·α。令 L = log₂(σ/σ₀)，C = log₂σ₀ + C₀，则：

|D_f - α| = |log₂Δ₀ - αC| / (L + C) < 0.1·α

即 L > |log₂Δ₀ - αC| / (0.1·α) - C

取 Δ₀ = 10，σ₀ = 1，C = 2.047，则 L > 18.4。

## 附录 D：真实布尔网络的 D_f 分析

### 1. 目的

验证信息投影框架在**真实生物网络**上的行为。具体问题：真实基因调控网络的 D_f，与相同规模的随机布尔网络是否有显著差异？

### 2. 数据

生物模型数据库 BBM（BioDivine Boolean Models），共 285 个 `.bnet` 文件。可处理（N ≤ 183）的模型 28 个，其中：

- 精确枚举（N ≤ 16）：13 个
- 蒙特卡洛采样（N > 16，M = 100000 次采样）：15 个

### 3. 方法

对每个网络，定义：

- **Ω**：所有初始状态（2^N 个）
- **M′**：吸引子（表型）
- **D_f = H(Ω|M′) / H(Ω)**

当 N ≤ 16 时，精确枚举所有初始态。当 N > 16 时，用 100000 次随机采样估计。

### 5. 观察

**观察一**：大 N 的 D_f 趋近 1。N ≥ 28 的网络，D_f 全部 > 0.9。

**观察二**：小 N 的 D_f 分散。N ≤ 15 的网络，D_f 分布在 0.72-1.00。

**观察三**：这个规律可以用公式预言：

D_f = 1 − H(吸引子) / N

当 N 大时，H(吸引子)/N → 0，所以 D_f → 1。当 N 小时，H(吸引子)/N 不可忽略，D_f 有结构。

### 6. 结论

**真实生物网络的 D_f，符合数学预期。**

- 大网络趋近 1，小网络分散
- 这个规律不依赖于网络是真实的还是随机的
- **真实网络没有偏离随机网络的数学基线**

**这是一个验证性结果，不是发现。** 它说明：信息投影框架在真实生物网络上成立，但没有产生新的生物学洞见。

### 7. 局限

- 样本量小（28 个模型）
- 285 个模型中大部分被跳过（N > 183 或解析失败）
- 蒙特卡洛采样引入了误差
- 没有和随机网络做严格对照

**要得到统计学结论，需要更多模型和更严格的方法。**

## XV. 证伪条件

1. 若经济学家发现，存在某个宏观描述 M′，使得 D_f ≈ 0，且能用它精确逆推微观状态，则信息投影框架的"结构性边界"结论在经济学中不成立。
2. 若物理学家在量子引力里找到一种投影，使得 D_f = 0，则信息投影框架在物理学中不适用。
3. 若数学上证明，虽然 g ∘ f 非单射，但存在某个逆推算子的误差下界为 0，则信息投影框架的定理被推翻。
4. 若数值模拟显示，标度律 D_f → α 不成立，则本文 6.4 节的结论被证伪。
5. 若证明离散情形可以写成 Δ ~ σ^α 的形式，则本文 6.5 节的结论被证伪。
6. 若在 Ising 模型中，D_f 的极小值不在临界点附近，则本文第七节的结论被证伪。
7. 若发现 D_f 在可逆动力学下时间不对称，则本文第八节的负面结果被推翻。
8. 若发现真实布尔网络的 D_f 系统性地偏离随机基线，则附录 D 的结论被证伪。
