# 生存强制力与美国制造业就业衰退：一种政治经济学的因果重构

> **核心论点**：美国制造业就业衰退的根本原因在于其内部的资本逻辑、金融化进程与自动化替代，而非中国制造业的崛起。本文提出“生存强制力”概念，并通过引入**户籍制度（Hukou）** 以及 **“地方政府间竞次竞争（inter-jurisdictional race-to-the-bottom）”** 作为外生制度性锚点，将其从描述性感叹重构为可检验的因果机制。将美国制造业就业衰退归咎于中国，是一种服务于国内政治议程的“外部归因谬误”。

# I. 摘要

本研究旨在解构“中国工人抢走美国制造业岗位”这一流行叙事。与既有计量经济学文献（Autor, Dorn & Hanson, 2016）不同，本研究不采用回归识别策略，而是采用**过程追踪法（Process-Tracing）** 进行因果推断。

本文的分析框架由三个维度构成：制度锚点、外部归因谬误与结构性转移。具体而言：

- **制度锚点（Institutional Anchor）**：中国户籍制度通过锁定农民工的城市公共服务获取权，极大地提高了劳动力退出低端制造业的沉没成本，从制度上固化了“生存强制力”。
- **外部归因谬误（External Attribution Fallacy）**：美国制造业就业占比自1950年代起持续下降，这一趋势早于中国入世（2001）数十年。
- **结构性转移（Structural Shift）**：自动化与金融化是去工业化的主导驱动力，中国在全球生产网络中是可替代的节点，而非根源。

本文所使用的“全球资本”或“跨国资本”是一个分析性概念，指代全球生产网络中具有跨边界流动能力的资本集合，而非对资本主义内部利益分化的完整描述。本文的分析聚焦于全球生产网络中的资本-劳动分配关系，不试图涵盖资本内部的部门间竞争。

**关键词**：生存强制力 · 户籍制度 · 竞次竞争 · 外部归因谬误 · 美国去工业化 · 全球资本逐利 · 过程追踪法

# II. 文献定位与学术对话

在进入正式分析前，有必要明确本文在既有学术版图中的位置。关于美国去工业化，学界主要存在三条竞争性解释路径：

1. **贸易冲击说**（Autor et al., 2016; Feenstra & Hanson, 1999）：认为中国等新兴经济体的进口竞争对美国地方劳动力市场造成了显著的就业挤出。
2. **技术替代说**（Acemoglu & Restrepo, 2020）：强调工业机器人与自动化对常规体力劳动的系统性替代。
3. **金融化挤压说**（Krippner, 2011; Stockhammer, 2004）：认为金融部门对实体经济的利润侵蚀导致了制造业投资的长期萎缩。

本文不试图通过计量手段对这些假说进行“裁决”，而是聚焦于一个更狭窄的靶向目标：**解构“中国是主因”这一政治叙事在因果逻辑上的谬误**。本文的贡献在于引入制度变量（户籍与地方政府间竞次竞争）作为连接全球结构（资本流动）与个体行为（超长工时）的中层机制（Meso-level Mechanism）。

# III. 理论框架与方法论声明

## 核心概念的因果重构：从循环论证到制度锚点

本文的核心概念“生存强制力”（Survival Compulsion）在既有版本中面临“循环论证”的风险（即“工资低是因为没得选，没得选是因为工资低”）。

在正式展开分析前，有必要先区分“生存强制力”与经典发展经济学中的“贫困陷阱”（Poverty Trap）概念。贫困陷阱强调的是收入水平与资本积累之间的恶性循环：低收入 → 低储蓄 → 低投资 → 低收入。“生存强制力”则强调的是**制度性锁定**——即使收入水平提高（如中国近年工资上涨），工人仍然因为户籍制度、公共服务的城乡分割、地方财政竞争等制度因素而无法有效转化为议价能力。“生存强制力”是制度性的，而“贫困陷阱”是收入性的。本文的贡献在于将“生存强制力”锚定于可识别的制度变量，从而使其超越“贫困陷阱”的宏观概括，成为一个可检验的中层理论概念。

为避免“循环论证”的逻辑困境，本文引入**外生于个体工资水平的制度性变量**，将其作为“生存强制力”的因果锚点：

- **户籍制度（Hukou）**：流动人口无法在工作地享有平等的医疗、养老与子女教育权利 → 缺乏永久定居预期 → 退出劳动力市场的心理与实际成本极高 → 即使面对超长工时与低薪，工人仍选择忍受。
- **地方政府间竞次竞争（Inter-jurisdictional race-to-the-bottom）**：地方政府为吸引制造业投资，通过低价供应工业用地、提供税收减免等方式降低企业运营成本，而劳动力成本是其中最具弹性的调节变量。这种竞争内在地抑制了制造业工资的整体上涨空间。
- **全国性剩余劳动力池（National labor reserve）**：农村转移劳动力持续涌入制造业，形成“就业后备军”，对现有工人的议价能力构成结构性压制。

需要说明的是，户籍制度主要锚定的是占制造业一线劳动力主体的农民工群体。城市本地工人同样面临产业结构单一化、高房价和技能贬值带来的流动困境，但户籍锁定为“生存强制力”提供了最直接、最可操作的制度性解释——它并非唯一来源，却是最主要的刚性锚点。

**可能反驳一：纯粹的供需模型是否足以解释中国工人的低薪酬？**

*可能的反驳*：“中国工人的低薪酬不过是劳动力市场供需关系的自然结果——人太多了，工资自然低。何必引入‘生存强制力’这样一个概念？”

*回应*：纯粹的供需模型无法解释一个关键事实：中国劳动力总量自2022年起已进入负增长，但制造业工资并未出现与生产率同步的显著上涨。这说明存在**超越市场机制的体制性压制**——户籍制度与地方政府竞次共同抬高了工人的“退出门槛”，使市场均衡点被长期压制在完全竞争水平以下。供需逻辑本身无法产生这种“黏性”，需要引入制度变量才能解释。

由此，“生存强制力”不再是“穷就是因为穷”的同义反复，而是 **“制度性锁定（Institutional Lock-in）+ 财政竞争（Fiscal Competition）+ 劳动力后备军（Labor Reserve）”** 三重机制叠加导致劳动力弹性趋于零的必然结果。

## 方法论声明

本文明确声明：**本文不采用计量经济学的回归-识别策略，而是采用政治经济学中成熟的“过程追踪法”（Beach & Pedersen, 2013）进行因果推断。** 即：通过检验时间顺序、机制证据和替代解释的排除，来评估因果主张的有效性。本文的核心论据（时间序列先行性、第三方替代转移、利润分配结构）均在过程追踪法的逻辑框架内展开。

具体而言，本文的过程追踪操作包括三个步骤：

> （1）**检验时间顺序**：美国制造业就业下降是否先于中国制造业崛起？——数据显示，下降趋势始于1950年代，远早于2001年中国入世。

> （2）**检验机制证据**：中国工厂的“可见性”是否等同于因果影响力？——本文论证“被看见”不等于“造成伤害”，中国工厂是资本逐利逻辑的节点而非源头。

> （3）**排除替代解释**：是否真的是中国而非自动化导致了美国岗位流失？——Hicks & Devaraj (2015) 的研究指出，2000至2010年间，87.8%的岗位流失源于生产率提升（自动化），贸易因素仅占13.4%。

# IV. 引言：被误读的因果链

2025年，美国制造业就业占总就业的比例降至 **8.0%**，为历史最低点。与此同时，“中国抢走了我们的工作”成为大选中屡试不爽的政治口号。然而，这一叙事建立在一个被忽视的前提之上：**中国工人的“竞争力”从何而来？**

在展开分析之前，有必要明确本文所使用的核心概念。本文中的“美国制造业就业衰退”特指**美国制造业就业占总就业比例的长期下降趋势**，而非制造业产出或增加值的减少。事实上，美国制造业增加值在GDP中的占比在过去四十年中基本保持稳定（约10%-12%），下降的是劳动力就业份额。这一区别对于理解本文的论证至关重要——本文所讨论的“衰退”是劳动力层面的社会性衰退，而非产业层面的技术性衰退。

本文将从三个层面展开分析：制度锚定下的生存强制力如何塑造中国工人的劳动处境；美国制造业就业衰退的真实原因在时间序列与第三方转移中如何呈现；全球利润分配中的赢家究竟是谁。

# V. 制度锚定与生存强制力：中国工人的真实处境

## 工时：远超法律上限

2025年，全国企业就业人员周平均工作时间为 **48.6小时**，远超《劳动法》规定的每周44小时法定上限。制造业一线职工普遍实行“12小时工作制、单休”。按年均计算：**2,527小时/年**，较美国制造业工人年均工时（BLS, 2025；约1,700小时）多出约800小时。

## 薪资：强度与回报的脱节

农民工占中国制造业一线劳动力的主体（国家统计局，2025；参见《2025年农民工监测调查报告》），其工资与劳动条件直接决定了中国制造业的整体成本面貌。

2025年，中国规模以上企业生产制造及有关人员年平均工资为 **80,739元**（约合 **1.1万美元**）。

> **数据说明**：上述数据来自“规模以上企业”，其统计口径偏向大中型正规企业，实际中小型制造业企业的工资水平更低。这意味着本文引用的数据可能**高估**了中国制造业工人的平均收入，“生存强制力”的实际强度比账面数字更为严峻。

先看生产效率，再看工资对比：

以特斯拉工厂为例：上海工厂工人的生产效率是美国工厂的2倍以上——但上海工人年薪仅约 1.4-1.5万美元，美国工人年薪约 8.25万美元。**中国工人工资仅为美国的 17%**。

美国制造业工人平均年薪约7万美元以上。**中国工人年薪约为美国的六分之一至七分之一**。

需注意，以上为名义汇率换算，这是跨国资本进行全球选址时直接面对的货币成本口径。按购买力平价（PPP）调整后，中国工人的实际福利差距有所缩小，但资本逐利决策以名义成本为依据，故名义比较在本文分析语境中具有优先效力。

## 制度锁定的多重机制：户籍、债务、产业与属地福利

农民工占中国制造业劳动力的主体。其“生存强制力”由多重结构性力量共同塑造：

1. **户籍制度锁定退出成本**：由于户籍限制，流动人口无法在工作所在地获得平等的公共教育、医疗和养老资源。辞职返乡不仅意味着失去当前工资，还意味着切断在城市积累的社保关系和社会网络。工人的“威胁点”（Threat Point）——即不工作时的最低生存保障——极低。
2. **地方政府间竞次竞争**：为吸引制造业投资，地方政府通过低价供应工业用地、提供税收减免等方式降低企业运营成本，而劳动力成本是其中最具弹性的调节变量。这种“竞次”内在地抑制了制造业工资的整体上涨空间。
3. **全国性剩余劳动力池**：农村转移劳动力持续涌入制造业，形成“就业后备军”（reserve army of labor），对现有工人的议价能力构成结构性压制——“你不干，有的是人干”并非修辞，而是制度性现实。

## 本地户籍工人的锁定困境

户籍制度解释的是农民工群体的锁定机制，但本地户籍工人同样面临议价权缺失。这意味着“生存强制力”不是户籍制度的专属产物，而是由多重锁定机制叠加形成的普遍结构性现象。本地户籍工人的锁定来源包括：

- **高房价与消费负债**：房贷、车贷、消费贷构成“债务锁定”，使工人不能轻易退出劳动市场。即使拥有本地户籍，高房价和偿债压力也使“不工作”的成本极高。
- **产业结构单一化**：许多城市依赖单一产业（如煤炭、钢铁、纺织），一旦该产业衰退，工人即使有户籍也缺乏替代就业选择。
- **技能折旧与年龄门槛**：制造业工人的技能在技术迭代中迅速贬值，加上年龄限制，导致“想走也走不了”的局面。
- **社会保障属地化**：即使拥有户籍，养老金、医保等福利的领取也高度依赖持续就业。断缴即意味着福利中断，这本身构成了“制度性锁定”。

需要强调的是，户籍制度并非“生存强制力”的唯一来源，而是其中最可辨识的制度性锁扣。本地户籍工人的处境表明，锁定机制是多因素叠加的结果。因此，本文所论“生存强制力”是 **“制度锁定（户籍与属地福利）+ 经济锁定（债务与房价）+ 结构锁定（产业单一与技能折旧）”** 多重机制叠加的系统性压制结构，远超出任何单一制度解释。

## 健康与家庭代价

2024年全国报告职业病新病例 **11,289例**；据国家卫健委历史累计数据，全国累计报告职业病约 **105万例**。全国约 **6,693万名留守儿童** 与流动人口父母长期分离。这些数据是上述制度锁定在个体生命体验上的直接外化。

# VI. 外部归因的祛魅：美国制造业就业衰退的多重因果

在厘清中国工人“竞争力”的真实来源与制度成本后，我们现在回到本文的初始问题：这种以生存强制力为代价的制造业体系，是否真的是导致美国制造业就业衰退的原因？

## 长期趋势的先在性：时间序列的反事实检验

美国制造业就业占总就业的比例：

| 年份 | 制造业就业占比 |
| :--- | :--- |
| 二战结束时 | 38% |
| 1950年代初 | >30% |
| 1990年 | 16.2% |
| 2000年 | 约14% |
| 2025年 | 8.0% |

这一下降趋势持续了**70余年**，其斜率并未在2001年中国入世后发生显著的结构性突变。**时间序列的先行性**（Trend Priority）不支持“中国入世导致美国制造业就业衰退”的因果方向。

值得注意的是，美国制造业的产出增加值（GDP贡献）并未同步下降，仍维持在GDP的约10%左右。这一“产出不变、就业锐减”的剪刀差，恰恰印证了**自动化替代**才是岗位流失的主因，而非进口替代。

**可能反驳二：绝对就业人数的下降是否说明问题？**

*可能的反驳*：“你用的‘制造业就业占比’分母在变大（服务业扩张），分子在变小。如果把绝对就业人数拿出来看，2000年后确实少了几百万。这不就是中国的冲击吗？”

*回应*：绝对就业人数从2000年的1720万降至2025年的1270万，确实减少了450万。但关键问题是：**这450万的减少是线性延续，还是2001年后加速？** 数据显示，1980-2000年间美国制造业就业已经在稳步下降（从约1900万降至1720万）。中国入世后下降斜率略有增加，但没有出现“断崖式”的结构性断裂。更重要的是，2011年后中国出口增速放缓，美国制造业就业继续下降——这直接否定了“中国入世=美国失业”的单向因果叙事。

## 正面回应“中国冲击”反例

Autor, Dorn 和 Hanson (2016) 的经典研究确实证明了中国进口冲击对美国特定地区（铁锈带）的负面效应。本文的回应如下：

1. **局部性与宏观性**：该研究的发现集中于地理上的局部区域，并未证明进口冲击是美国全国制造业就业占比长期下行的**主要驱动力**。
2. **时间序列检验**：2011年后中国劳动力成本上升、出口增速放缓，若中国是主因，美国制造业应出现反弹。然而事实是，**2011至2025年间，美国制造业就业占比从约10%降至8.0%**，无趋势性逆转。
3. **第三方替代转移**：2011年后美国岗位并未回流，而是大量转移至越南、墨西哥等成本更低的国家。这表明驱动力是**全球资本逐利**，中国是链条中最大的节点，而非源头。
4. **归因权重**：Hicks & Devaraj (2015) 的研究指出，2000至2010年间，87.8%的制造业岗位流失源于生产率提升（自动化），贸易因素仅占13.4%，其余因素包括企业外迁与统计误差等。

在这13.4%的贸易因素中，中国的具体贡献权重超出了本文的数据范围，也不影响本文的核心判断。即使将贸易因素全部归因于中国（即给予中国冲击效应的最极端假设），贸易因素在总量中的占比（13.4%）仍远低于国内结构性因素（87.8%）。换言之，即使在中国冲击效应被极端放大的假设下，中国因素也只能解释美国制造业岗位流失的约13.4%，而国内结构性因素解释了约87.8%。因此，即使在这种最极端假设下，“中国是主因”这一宏观叙事在数量级上仍然不成立。

**可能反驳三：Autor的计量回归是否比定性推断更有说服力？**

*可能的反驳*：“Autor 的研究用的是严格的工具变量法，控制了内生性。你只是画了几张趋势图、做了几个时间对比，凭什么说你的定性推断比他的计量回归更有说服力？”

*回应*：本文不声称“更有说服力”，而是声称“回答不同的问题”。Autor 回答的是“中国进口对特定地区的**局部**就业是否有负面冲击”——答案是“有”。本文回答的是“中国是否是美国全国制造业就业长期下降的**主因**”——答案是“不是”。一个局部冲击可以被证实，同时不改变它作为次要变量的地位。本文的论证策略是：**即使全盘接受 Autor 的估计值，将其放大到极端上限，国内结构性因素（自动化+金融化）依然在数量级上占优。**

## 去工业化的结构性矩阵

| 主因 | 具体机制 |
| :--- | :--- |
| **金融化** | 华尔街年化回报率（10%-15%）持续吸走实体经济资本。 |
| **自动化** | 工业机器人密度上升直接替代常规体力劳动。 |
| **教育脱节** | 职业教育体系未能向高端制造输送足够的技术工人。 |
| **基建老化** | 平均超过50年的基础设施推高本土物流成本。 |

## 为什么是“中国工人”，而不是华尔街或机器人？

以上是从“因果数据分析”与“结构性权重分配”的层面证明中国并非主因。然而，一个更深层的政治传播学问题仍然需要回答：既然数据趋势如此清晰，为何“中国抢走工作”的叙事依然如此流行且极具动员力？

在完成对“中国主因论”的数据驳斥后，一个更深层的问题仍然悬而未决：**既然华尔街的金融化与工业自动化才是美国岗位流失的主要驱动力，为何“中国工人”而非“银行家”或“机器人”成为众矢之的？**

本文认为，这一现象需要从四个层面加以解释：

第一，**阶级掩盖（Class Camouflage）**：指责华尔街意味着质疑整个金融化资本主义体系，挑战美国最有权势的精英阶层；指责自动化则与美国“技术崇拜”的文化基因相冲突。唯有指责一个没有美国投票权、没有游说能力的外部群体，才能在不动摇国内权力结构的前提下释放政治压力。

第二，**认知可见性（Cognitive Visibility）**：资本流动是抽象的，自动化进程是沉默的，而中国工厂与中国商品是高度可见的。人类认知天然偏好将复杂系统性后果归因于具体可见的行动者，而非抽象的结构性力量。

第三，**意识形态他者化（Ideological Othering）**：中国被塑造为“自由世界”的对立面，这使反华叙事天然带有捍卫美国生活方式与价值观的道德动员力——这一修辞无法同等应用于德国（高自动化但属西方阵营）或墨西哥（低成本但为政治附庸）。

第四，**时间锚定效应（Temporal Anchoring）**：中国于2001年加入WTO，恰与美国制造业就业占比加速下降的时间窗口重叠。这一纯粹的时间巧合，被政治操盘手转化为“中国入世 = 美国失业”的因果叙事，为公众提供了清晰、简单且极具煽动性的解释框架。

**可能反驳四：“被看到”是否等于“造成伤害”？**

*可能的反驳*：“你一边说‘中国不是主因’，一边又说‘中国工人被骂是因为认知可见性’。这不等于承认中国工人确实‘挡在了前面’吗？如果中国工厂不是那么大、出口不是那么多，美国工人也不会骂他们。这难道不是中国‘抢饭碗’的另一种表述吗？”

*回应*：两者有本质区别。“被看到”不等于“造成伤害”。一个路标可以指向事故地点，但它不是事故的原因。中国工厂和商品之所以“可见”，是因为跨国资本选择了中国作为生产节点——而资本之所以选择中国，恰恰是因为中国的制度结构提供了最具弹性（即最廉价）的劳动力供给。**美国工人“看到”的是中国工厂，但“看不到”的是促使资本家把工厂搬到中国去的制度性驱动力——包括华尔街的回报率要求、美国的贸易政策，以及中国地方政府为招商引资而压低劳动力成本的竞次逻辑。** 被看见的是节点，被忽略的是推动节点的结构力。

综上，“恨中国工人”并非经济理性的结果，而是一套高度有效的政治传播机制——它将结构性矛盾转化为族群间对立，既安抚了受害者的情绪，又保护了真正的获益者。

## “生存强制力”消退之后：资本转移与全球竞次

**可能追问与回应五：中国工资上涨后资本转移是否证明了“剥削驱动增长”？**

*读者追问*：“你说中国工人的低工资是‘生存强制力’的结果。那现在中国工资涨了，资本开始往越南、墨西哥跑了。这不正说明中国以前的竞争力就是靠‘低工资’吗？跟‘生存强制力’有什么关系？这难道不是证明了‘剥削驱动增长’这个逻辑吗？”

*回应*：这个追问恰好触及了问题的核心，也暴露了“中国抢走美国工作”这个叙事的**另一层盲区**。

首先，我们需要区分两个问题：
- **问题 A**：中国制造业的早期扩张是否利用了低工资？——答案是肯定的。
- **问题 B**：美国制造业的长期就业衰退是否**由**中国的低工资造成？——答案是否定的。

问题 A 和问题 B 是**两个独立的问题**。承认 A 为真，并不自动推导出 B 为真。

其次，**“资本离开中国”恰恰证明了“中国不是主因”**。为什么？

如果美国工人失业的根源是“中国的低工资”，那么当中国工资上涨、资本离开中国时，美国制造业就业理当出现**系统性回流**。但事实是：
- 2011年后中国劳动力成本持续上升；
- 资本没有回流美国，而是转向了**越南、墨西哥、印度、菲律宾、印度尼西亚**等劳动力成本更低的国家；
- **越南**2025年吸引外资超380亿美元，制造业占82.8%（越南统计总局，2026）；中国对**墨西哥**投资存量在2022-2025年间增长46%（墨西哥经济部，2026），主要集中在汽车与新能源领域。
- 同期美国制造业就业占比继续从约10%降至8.0%。

这说明什么？**美国工人失去的岗位，从来不是“被中国工人抢走的”，而是被“全球资本寻找最低成本”这个结构性逻辑甩下的。** 中国只是这条流水线上曾经最大的那个节点——当这个节点的成本上升，资本就换一个节点，而不是回到美国。

更深一层：越南、墨西哥、印度、菲律宾、印度尼西亚的工人，正在承受类似中国工人曾经承受的“生存强制力”——超长工时、低薪、缺乏保障。**这不是“中国特有”的现象，而是全球资本在每一个“有限区间”内寻找最低生存成本的必然投射。**

所以，中国工资上涨、资本转移这件事，**不但没有反驳“生存强制力”这个概念，反而证明了它的普遍性**——它不是一个国家的故事，而是一个全球系统的故事。

美国工人输给的从来不是“中国工人”。他们输给的是一个**由全球资本、跨国供应链和金融化体系共同驱动的竞次系统**。中国工人只是这个系统中付出最多、被骂得最凶、拿得最少的那一环。

# VII. 结构性转移：全球利润分配与赢家通吃

以一部售价 **1,000美元** 的iPhone为例：

| 环节 | 利润/成本占比 |
| :--- | :--- |
| **苹果公司** | **58.5%** |
| 原材料成本 | 21.9% |
| 韩国供应商 | 4.7% |
| 美国其他企业 | 2.4% |
| 欧盟 | 1.1% |
| 日本 | 0.5% |
| 中国台湾 | 0.5% |
| **中国大陆组装成本（含人工）** | **仅 1.8%** |

> **数据解读**：上述 **1.8%** 是“整机组装成本”占售价的比例，包含厂房折旧、设备维护、水电、物流、管理成本及辅料等多项支出，并非工人工资的直接占比。即便乐观估计工人工资占组装成本的50%，每位工人从一台iPhone中获得的报酬也仅约 **90元**（按国行售价9,999元计），**不足售价的1%**。

苹果拿走近六成的利润，而真正用手组装这部手机的中国工人，最终只拿到不足售价1%的报酬。

**全球化真正的结构性赢家是跨国资本，而非中美两国的产业工人。**

**可能反驳六：低技术组装环节是否理应拿得少？**

*可能的反驳*：“中国工人只做最低端的组装环节，技术含量低，拿得少是理所当然的。跟苹果比利润分配没有意义。”

*回应*：如果单纯以“技术含量”决定回报，那么当中国工人以**两倍于美国同行的效率**完成同等工序时（见2.2节特斯拉案例），其单位劳动回报理应享有优势，而不是劣势。真正的差距不在于“技能高低”，而在于**全球生产网络中分配权力的极度不对称**——德国或日本从事类似组装工作的工人，其报酬显著高于中国同行，不是因为他们的“技术含量”更高，而是因为他们所在的劳动力市场具有更强的制度性议价能力（工会覆盖率、最低工资法执行力度、社会保障的普惠性）。中国工人的低所得，不是“技能”问题，而是“议价权”问题。

# VIII. 讨论：结构性困境中的缓解性路径

在承认当前结构性趋势的惯性与不可逆性的前提下，本文仍认为有必要指出各国可在边际上采取的缓解性措施——这些建议的目的不在于逆转趋势，而在于降低趋势演进中个体所承受的痛苦与代价。

需要特别说明的是，本文所分析的“生存强制力”依赖于当前中国制度环境的若干关键特征：户籍制度的城乡二元结构、地方政府竞次竞争的财政激励、以及劳动法执行力度不足。如果这些制度条件发生结构性变化，“生存强制力”的强度将随之改变——这正是本文第十章“证伪条件”中所设定的可检验命题。换句话说，“生存强制力”不是一个本体论意义上的“永恒本质”，而是一个在特定制度条件下产生的历史性现象。它的可变化性是本文可证伪性的保证。

基于前文论证，美国去工业化与中国的“生存强制力”均为全球资本流动的结构性产物，而非单一国家的政策失误所致。因此，本文不提供“逆转趋势”的处方，而是指出在各国内部框架内**缓解最尖锐分配矛盾**的可能方向：

- **对于美国**：职业教育体系的重建与基础设施更新，虽无法逆转自动化趋势，但可提高本土剩余制造业岗位的匹配效率。
- **对于中国**：劳动法的严格执行与户籍制度的渐进改革，虽无法消除全球资本逐利压力，但可提高工人在劳资博弈中的底线议价能力。

当中国的“生存强制力”因制度性或人口结构性变化而减弱时，全球资本不会返回美国，而是会继续向越南、墨西哥、印度、菲律宾、印度尼西亚等成本更低的承接地迁移。这一趋势正在发生，并进一步证实了本文的核心判断：美国制造业就业衰退的根源不在于“中国”，而在于全球资本逐利的结构性逻辑。

以上方向不构成对结构性趋势的反转承诺，仅作为降低个体痛苦的边际调整。

# IX. 证伪条件与学术自觉

本文的核心判断包含两个层面：
1. **外部归因是错的**：美国制造业就业衰退的主因不是中国制造业的崛起。
2. **生存强制力是实的**：中国工人的低薪酬源于制度锁定。

如果以下任何一条在 **5年内**发生，本文的核心结论即需要被修正或推翻：

1. **美国制造业就业占比出现持续回升（年均增长 +0.3%以上），且同期中国制造业对美出口份额未出现同比例的大幅下降**——则“中国非主因”的论点被削弱。
2. **中国制造业工人实际薪资（经购买力平价调整后）达到美国同岗位薪资的 40% 以上，且同期中国制造业全球出口份额不降反升**——则“生存强制力”解释失效。
3. **美国跨国公司在华子公司利润占比显著下降（降幅超过30%），同时美国本土制造业投资占比持续回升（持续5年）**——则“资本逐利是主因”的判断需修正。

> **注**：如果薪资上涨导致出口竞争力大幅下降，则不构成推翻——这仅仅是成本上升的自然结果。只有当薪资上涨与竞争力上升同步发生时，才真正推翻“生存强制力”解释。
