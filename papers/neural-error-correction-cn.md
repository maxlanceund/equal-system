## I. 摘要

本文用信息损失率 D_f 定量测量了神经网络中间层的信息分布。核心发现有九个：

**第一，信息主要分布在神经元之间的关联里，而非单个神经元里，也不集中在少数"重要"神经元。** 对 h1 层（128 个神经元），单神经元的平均 D_f = 0.85，破坏关联后 D_f = 0.64，保留关联的 D_f = 0.16，关联贡献 75%。逐层扫描显示：所有隐藏层的关联贡献占比都在 52-75% 之间。按方差排序逐步加入神经元，D_f 从 1.000 缓慢降到 0.355，与随机排序几乎相同——方差挑不出"重要神经元"，信息分散在所有神经元里。当输出层被维度锁死时，丢失的信息会迁移到它与倒数第二层的联合分布里，迁移阈值约为 0.8 × 类别数。

**第二，部分打乱曲线呈凸形，表明存在纠错码结构。** 打乱 h1 中 40% 的神经元，D_f 仅上升 6%；打乱 50%，上升 9%；但打乱 80% 后，D_f 上升 43%。

**第三，纠错阈值随层宽度增强。** h1=32 时，打乱 50% 损失 29% 的信息；h1=128 时损失 9%；h1=512 时仅损失 3%。

**第四，纠错码在训练的第一个 epoch 内被激活，并整体提升信息保留。** 随机初始化时，norm@50 = 0.353。训练 1 个 epoch 后，norm@50 降到 0.224。之后 30 个 epoch，稳定在 0.22-0.28。对照实验显示：训练后每层 D_f 大幅下降（layer1 从 0.472 降到 0.256，output 从 0.777 降到 0.389），输入层不变。**训练在第一个 epoch 内，同时"激活纠错"和"提升信息保留"。**

**第五，输出层 D_f 被维度锁死。** 输出层只有 10 维，D_f 被锁在 0.6 附近，不能反映网络质量。宽度扫描显示：h1 从 16 扩到 1024，h1 单层 D_f 从 0.645 降到 0.060，但输出层 D_f 纹丝不动（0.61-0.62）。与准确率的相关系数：D_f 只有 -0.52（弱），margin_mean 是 +0.98（强），out_entropy 是 -0.99（最强）。**输出熵和 margin 才是准确率的强预测子。** 完整训练曲线显示：40 epoch 内 D_f 在 0.56-0.71 之间震荡，无净趋势；margin 从 -0.024 单调升到 10.8。

**第六，关系是低秩的，有效秩随类别数增长，但增长形式取决于训练充分度。** 训练 10 epoch（准确率 88-97%）时，有效秩满足 r_eff ≈ 1.25 × 类别数（k ≤ 10），拟合 r_eff − k = 1.26 · log₂(k)。训练充分（准确率 97-99%）后，有效秩显著升高（k=10 时从 12.35 升到 19.58），但不服从简单公式，且在高 k 处出现抖动。**有效秩是"任务 + 训练 + 架构"三者共同决定的。**

**第七，在全连接网络的直接投影层，"背景模式"是架构驱动的。** 对 MNIST（全连接网络 h1 层），互信息矩阵最大的特征模式与类别无关（MI = 0.433），且与图像对比度/亮度强相关（-0.942 / -0.941）。这个"背景模式"不随任务变，是架构的属性。

**第八，背景模式与类别模式的分离，只在"直接投影层"成立。** 对 CIFAR-10（CNN，h1 在卷积层之后），有效秩降至 4.78，背景模式与亮度几乎无关（-0.076），没有明显的背景/类别分离。这说明分离结构取决于投影的层次：直接投影保留输入的全局统计，卷积后的投影不保留。

**第九，有效秩在高类别数和充分训练下出现饱和。** 20 类任务的有效秩只有 8.73，低于 10 类的 12.00；长训练到 30 epoch 仍未饱和（8.39 → 10.01）。这说明有效秩既受训练充分度影响，也受架构维度限制。

**与黑洞物理的对应：** 这些结果定量对应 AdS/CFT 对偶中的量子纠错码图景。"背景模式"对应视界几何本身，"类别模式"对应落入物质的信息，两者的分离结构与黑洞纠缠谱的"背景 + 信号"结构一致。而"分离只在直接投影层成立"对应全息原理中"边界必须是最外层"这一细节。"信息迁移"对应黑洞信息悖论的岛屿机制。

**本文的定位：** 本文不是一个新物理发现，而是一个定量的跨系统对应。它给出八个之前未被报告的数：**纠错阈值随层宽度线性增强**、**纠错码在第一个 epoch 内被激活**、**有效秩受训练充分度强烈影响**、**迁移阈值 ≈ 0.8 × 类别数**、**背景模式与类别模式的分离**、**背景模式 = 直接投影层的输入全局统计量**、**有效秩在 20 类下饱和**、**逐层关联贡献占比 52-75%**。

## II. 引言

### 1. 核心问题

神经网络的信息，分布在单神经元里，还是神经元之间的关联里？

这个问题在机器学习中已有答案：**分布式表征**。Hinton 等人在 1980 年代就指出，神经网络的信息不是"局部"存储的，而是分布在大量神经元的激活模式里。

但"分布式"这个说法是定性的。本文的目标是把它变成一个定量的测量，并追问六个更深的问题：

- **信息有多少在关联里？**
- **这个分布是什么时候形成的？**
- **这个"关联"本身是什么结构？**
- **这个结构是任务驱动的，还是架构驱动的？**
- **背景模式在编码什么？**
- **这个结构在什么架构层次上成立？**

### 2. 工具：信息损失率 D_f

设 Ω 为要保留的信息（类别标签），M′ 为宏观描述（某一层的激活）。定义：

D_f = H(Ω | M′) / H(Ω)

- D_f = 0：M′ 完整保留了 Ω
- D_f = 1：M′ 完全不包含 Ω

### 3. 方法：破坏关联

关键操作：**独立打乱每一列的行顺序。**

- 打乱后，每列的边缘分布不变
- 但列与列之间的联合分布被破坏
- 如果信息在单列里，D_f 不变
- 如果信息在列之间的关联里，D_f 升高

### 4. 与黑洞物理的对应

2015 年，Almheiri、Dong、Harlow 提出，AdS/CFT 对偶本质上是一个量子纠错码。2019 年，Penington、Almheiri 等人用这个框架解决了黑洞信息悖论。

**本文的目标是：在神经网络上，定量重现这个结构。**

### 5. 论证结构

第三节给出方法。第四节报告关联分布。第五节报告纠错码结构。第六节报告宽度依赖。第七节报告训练激活与随机对照。第八节报告输出层锁死、逐层 D_f 分布、宽度扫描、信息迁移、完整训练曲线。第九节报告关系结构的低秩性、拟合形式、分离结构的边界以及高类别数反常。第十节报告背景模式的编码含义。第十一节讨论与黑洞的对应。第十二节报告一个被证伪的假设。第十三节讨论局限。第十四节为结论。

## III. 方法

### 1. 模型

全连接网络，输入 784（MNIST），输出 n 类。隐藏层配置可变。

训练：5000 张图，10 个 epoch，Adam 优化器，学习率 1e-3。测试：1000 张图。

### 2. 中间层激活

对每个测试样本，提取 h1 层的激活向量。得到矩阵 A ∈ R^{N × d}，其中 N = 1000，d = h1 维度。

### 3. D_f 估计

用 70/30 划分估计条件熵：

1. 将数据随机分为训练集（70%）和测试集（30%）
2. 在训练集上训练一个小分类器（128 隐藏单元，ReLU，50 epoch）
3. 在测试集上测交叉熵损失
4. D_f = CE / log(n_classes)

### 4. 损坏操作

**打乱：** 随机选 k 列，独立重排每列的行顺序。

### 5. null test

用随机标签替换真实标签，重复所有操作。

### 6. 互信息矩阵

对每一对神经元 (i, j)，用分箱法估计互信息 I(i, j)，得到对称矩阵 M。分析其：

- 有效秩（特征值分布的熵指数）
- 特征值间隙
- 前 k 个特征值的累积占比
- 每个特征模式与类别标签的互信息

### 7. 图像统计量

对每张图像，计算四个统计量：

- 亮度：像素均值
- 对比度：像素标准差
- 边缘密度：相邻像素差分的均值
- 高频占比：傅里叶变换中高频能量的占比

用 Spearman 秩相关系数分析特征模式与这些统计量的关系。

### 8. 模型比较设计

为测试"分离结构的普适性"，构造三个系统：

- **MNIST + 全连接网络**：h1 直接接在输入之后（直接投影）
- **CIFAR-10 + 全连接网络**：h1 直接接在输入之后（直接投影）
- **CIFAR-10 + CNN**：h1 在三层卷积之后（间接投影）

## IV. 结果一：信息在关联里

### 4.1 关联贡献

| 条件 | D_f |
| :--- | :--- |
| 单神经元平均 | 0.848 |
| 全部 128 神经元，破坏关联 | 0.644 |
| 全部 128 神经元，保留关联 | **0.159** |

关联贡献 = 0.644 - 0.159 = 0.485。归一化：0.485 / 0.644 = **0.753**。

**75% 的信息在神经元之间的关联里。**

### 4.2 null test

随机标签下，关联贡献 ≈ -0.008。说明真实标签下的 0.485 是真实信号。

### 4.3 结论

**信息不是实体的属性，是实体之间的关系。**

### 4.4 打乱曲线

见 V 节。

### 4.5 关联贡献是全网络的普遍规律

#### 1. 问题

"75% 的信息在关联里"是 h1 层的局部现象，还是所有层的普遍规律？

#### 2. 设计

对 6 层网络（784-128-64-32-16-10），逐层测：

- D_f(intact)：保留关联时的 D_f
- D_f(shuffled)：破坏关联时的 D_f
- corr_contrib = D_f(shuffled) − D_f(intact)：破坏关联后 D_f 升了多少
- corr_frac = corr_contrib / D_f(shuffled)：关联贡献占比

#### 3. 结果

| 层 | 维度 | D_f(intact) | D_f(shuffled) | corr_contrib | corr_frac |
| :--- | :--- | :--- | :--- | :--- | :--- |
| input | 784 | 0.041 | 0.087 | +0.046 | 0.524 |
| h1 | 128 | 0.158 | 0.638 | +0.480 | **0.752** |
| h2 | 64 | 0.239 | 0.824 | +0.585 | **0.710** |
| h3 | 32 | 0.321 | 0.901 | +0.580 | **0.644** |
| h4 | 16 | 0.391 | 0.937 | +0.546 | **0.583** |
| output | 10 | 0.457 | 0.950 | +0.493 | **0.519** |

#### 4. 观察

**一，所有隐藏层的 corr_frac 都在 0.52-0.75 之间。** "信息在关联里"不是 h1 的局部现象，是**全网络的普遍规律**。

**二，corr_frac 随层变窄而下降。** h1 的 0.752 → h4 的 0.583 → output 的 0.519。**层越窄，关联贡献占比越低**——窄层本身容量不够，关联也没太多空间可压缩。

**三，input 层的 corr_frac 只有 0.524。** 输入层几乎没有关联结构——输入是原始像素，本来就没有特征间关联。

**四，D_f(intact) 和 D_f(shuffled) 都随层变窄单调上升。** 这与 8.3 节一致：层越窄，单层保留的类别信息越少，无论是否保留关联。

#### 5. 结论

**"信息在关联里"是全网络的普遍规律，不是某一层的特性。**

**越靠近输入，关联贡献越大；越靠近输出，单层结构贡献越大。** 这是因为窄层的表示能力有限，关联也无处可压。

### 4.6 信息分散在所有神经元里，不在少数"重要"神经元

#### 1. 问题

信息是集中在少数高方差神经元里，还是分散在所有神经元里？

#### 2. 设计

对 h1 层（128 个神经元），按方差从大到小排序。逐步加入神经元，测 D_f 如何变化。

对照：随机排序，逐步加入神经元。

**判据：如果按方差排序远好于随机排序，说明信息集中在少数高方差神经元；如果两者差不多，说明信息分散。**

#### 3. 结果

**按方差排序：**

| 神经元数 | D_f |
| :--- | :--- |
| 0 | 1.000 |
| 1 | 0.925 |
| 2 | 0.908 |
| 4 | 0.850 |
| 8 | 0.863 |
| 16 | 0.771 |
| 32 | 0.703 |
| 64 | 0.580 |
| 96 | 0.444 |
| 128 | 0.355 |

**方差排序 vs 随机排序：**

| 神经元数 | 方差排序 | 随机排序 | 差距 |
| :--- | :--- | :--- | :--- |
| 1 | 0.897 | 0.917 | -0.020 |
| 8 | 0.862 | 0.821 | +0.041 |
| 16 | 0.801 | 0.768 | +0.033 |
| 32 | 0.710 | 0.657 | +0.053 |
| 64 | 0.573 | 0.564 | +0.009 |
| 128 | 0.388 | 0.372 | +0.016 |

#### 4. 观察

**一，D_f 下降非常缓慢、均匀。** 从 0 个（1.000）到 128 个（0.355），没有明显的"拐点"。不是"前几个神经元就够了"，而是每个神经元都贡献一点。

**二，方差排序和随机排序几乎一样。** 32 个神经元时只差 0.053，128 个时只差 0.016。**方差这个指标几乎挑不出"重要神经元"。**

**三，没有"少数关键神经元"。** 如果信息集中在少数神经元，方差排序应该远好于随机排序。但实际差不多，说明**信息是分散的，不是集中在少数"重要"神经元里**。

#### 5. 结论

**信息既不在单个神经元，也不在少数神经元，而是在全部神经元的联合分布里。**

**与 4.1 和 4.5 节的关系：**

- **4.1 节**：信息在神经元之间的**关联**里（打乱关联，D_f 升）
- **4.5 节**：关联贡献是全网络的普遍规律
- **本节**：信息不集中在少数"重要"神经元

**三者合起来：信息是全网络、全神经元、全关联的分布式表征。**

| 0.80 | 0.5444 | 0.4258 |

| 1.00 | 1.0918 | 1.1157 |

### 2. 曲线形状

前 40% 打乱：仅损失 5.9%。前 50%：损失 11.6%。后 50%：损失 88.4%。

**线性预测：打乱 50% 应该损失 50%。实际损失 11.6%。偏差 -38.4 个百分点。**

归一化曲线线性拟合：斜率 = 0.8644，截距 = -0.1586。

最大单步跳变：0.4282，在 frac = 1.00。

### 3. 结论

**打乱曲线是凸的。前一半神经元几乎"可牺牲"。**

这对应纠错码结构：**可以容忍一定比例的损坏而不丢失信息。** 超过阈值后，信息快速崩溃。

## VII. 结果四：纠错码在第一个 epoch 内被激活

### 7.1 问题

纠错码是随机初始化时就有的，还是训练出来的？

### 7.2 结果

| 条件 | norm@50 | 准确率 |
| :--- | :--- | :--- |
| 随机初始化（未训练） | **0.353** | — |
| 训练 1 epoch | **0.224** | 45.5% |
| 训练 30 epoch | 0.275 | 92.1% |

### 7.3 训练动力学（h1=128）

| Epoch | 准确率 | norm@50 |
| :--- | :--- | :--- |
| 1 | 45.5% | 0.224 |
| 2 | 77.0% | 0.226 |
| 3 | 78.5% | 0.216 |
| 5 | 84.3% | 0.239 |
| 8 | 87.3% | 0.225 |
| 12 | 89.6% | 0.226 |
| 16 | 90.6% | 0.264 |
| 20 | 90.9% | 0.236 |
| 25 | 91.6% | 0.230 |
| 30 | 92.1% | 0.275 |

### 7.4 结论

**纠错码不是"架构固有"（随机时弱，0.353），不是"渐进涌现"（不是慢慢增强），而是"一次性激活"。**

- 从随机到 epoch 1：norm@50 从 0.353 降到 0.224
- 之后 30 个 epoch：稳定在 0.22-0.28

**网络在第一个 epoch 内，就把信息分布结构"定下来"了。之后的训练只改"装什么信息"，不改"怎么分布信息"。**

### 7.5 对应

这对应全息原理的一个更深的主张：体-边界的编码结构不是"慢慢形成"的，而是在边界形成的瞬间就确定的。

### 7.6 对照实验：随机网络 vs 训练网络

#### 1. 问题

纠错码激活的同时，每一层的信息保留能力是否也在改变？

#### 2. 设计

同一架构（784-32-16-10），分别测：

- **随机网络**：初始化后不训练
- **训练网络**：训练 10 epoch，准确率 86.3%

逐层测 D_f。

#### 3. 结果

| 层 | D_f 随机 | D_f 训练后 | 差异 |
| :--- | :--- | :--- | :--- |
| input | 0.021 | 0.021 | -0.001 |
| layer1 | 0.472 | 0.256 | **-0.216** |
| layer2 | 0.758 | 0.359 | **-0.399** |
| output | 0.777 | 0.389 | **-0.388** |

#### 4. 观察

**一，输入层 D_f 不变。** 随机和训练后都是 0.021——输入本来就是原始数据，训练不动它。

**二，所有隐藏层的 D_f 大幅下降。** layer1 降 0.22，layer2 降 0.40，output 降 0.39。**训练让每一层都更好地保留了类别信息。**

**三，随机网络的 D_f 已经接近"随机水平"。** 随机 output 的 D_f = 0.777，训练后 0.389。**说明"随机网络的 D_f 高"不是因为架构锁死，而是因为它还没学到东西。**

#### 5. 结论

**训练不仅激活了纠错码，也整体提升了每一层的信息保留能力。**

**与 7.4 节的关系：**

- **7.4 节**：纠错码在第一个 epoch 内激活（norm@50 从 0.353 降到 0.224）
- **本节**：训练让每一层的 D_f 大幅下降

**两者是同一件事的两面：训练在第一个 epoch 内，同时"激活纠错"和"提升信息保留"。**

## VIII. 结果五：输出层锁死、逐层 D_f、宽度扫描、信息迁移、训练曲线

### 8.1 输出层 D_f 被维度锁死

| 配置 | 倒数第二层 D_f | 输出层 D_f | 准确率 |
| :--- | :--- | :--- | :--- |
| 64-32-10 | 0.490 | 0.609 | 89.4% |
| 64-32-128-10 | 0.190 | 0.615 | 89.3% |
| 64-32-512-10 | 0.100 | 0.655 | 90.1% |

**输出层 D_f 被输出层维度锁死。** 10 维的输出层，D_f 永远在 0.6 附近，无法反映网络质量。

### 8.2 输出熵和 margin 才是准确率的强预测子

#### 1. 设计

在宽度扫描的 6 个配置上，测 4 个量，并计算与准确率的相关系数：

- D_f(output)
- margin_mean
- out_entropy
- logit_scale

#### 2. 结果

| 配置 | acc | D_f | margin | out_H | logit |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 16-32-16-8 | 81.0% | 0.664 | 1.69 | 0.674 | 3.46 |
| 32-32-16-8 | 82.6% | 0.611 | 2.04 | 0.599 | 4.12 |
| 128-32-16-8 | 85.2% | 0.636 | 2.53 | 0.472 | 4.09 |
| 256-32-16-8 | 87.3% | 0.618 | 2.94 | 0.438 | 4.03 |
| 512-32-16-8 | 89.1% | 0.635 | 3.87 | 0.336 | 4.55 |
| 1024-32-16-8 | 88.5% | 0.591 | 3.75 | 0.352 | 3.52 |

**与准确率的相关系数：**

| 量 | 相关系数 |
| :--- | :--- |
| D_f_out | **-0.522** |
| margin_mean | **+0.976** |
| out_entropy | **-0.992** |
| logit_scale | +0.402 |

#### 3. 观察

**一，D_f 与准确率弱相关（-0.522），且不单调。** 从 16 到 1024，D_f 在 0.59-0.66 之间乱跳，看不出趋势。**D_f 不能预测准确率。**

**二，margin 单调上升（除 1024 略降），与准确率强相关（+0.976）。** 从 1.69 到 3.87，几乎单调。

**三，out_entropy 单调下降（除 1024 略升），与准确率最强相关（-0.992）。** 从 0.674 到 0.336，几乎单调。**输出熵是最强的单一预测子。**

**四，logit_scale 与准确率弱相关（+0.402）。** 它不是一个好的预测子。

#### 4. 结论

**输出熵和 margin 才是准确率的强预测子。D_f 不是。**

**原因：D_f 被输出层维度锁死（见 8.1 节）。** 无论网络好坏，10 维输出层的 D_f 都在 0.6 附近，无法区分。margin 和输出熵没有维度锁死的问题，能真实反映网络质量。

### 8.3 逐层 D_f 分布

对 6 层网络（784-128-64-32-16-10），逐层测量 D_f：

| 层 | 维度 | 单层 D_f |
| :--- | :--- | :--- |
| input | 784 | 0.089 |
| h1 | 128 | 0.215 |
| h2 | 64 | 0.348 |
| h3 | 32 | 0.480 |
| h4 | 16 | 0.595 |
| output | 10 | 0.657 |
| **全部隐藏层联合** | — | **0.159** |

**三个观察：**

**一，D_f 随层变窄单调上升。** 从 h1 的 0.215 升到 output 的 0.657。**层越窄，单层保留的类别信息越少。**

**二，联合隐藏层的 D_f 只有 0.159，远低于任何单层。** 信息不是分布在某一层里，而是分布在多层之间的关联里。这与第四节"75% 信息在关联里"一致。

**三，输出层锁死是"逐层锁死"的极端情况。** 不是输出层特别，而是维度越低、锁死越严重。

### 8.4 宽度扫描：h1 宽度对逐层 D_f 的影响

#### 1. 设计

固定后面层（32-16-8），只扫 h1 宽度：16、32、128、256、512、1024。

#### 2. 结果

| 配置 | h1 D_f | out D_f | 准确率 |
| :--- | :--- | :--- | :--- |
| 16-32-16-8 | 0.645 | 0.619 | 81.0% |
| 32-32-16-8 | 0.500 | 0.619 | 82.6% |
| 128-32-16-8 | 0.252 | 0.610 | 85.2% |
| 256-32-16-8 | 0.153 | 0.621 | 87.3% |
| 512-32-16-8 | 0.102 | 0.619 | 89.1% |
| 1024-32-16-8 | 0.060 | 0.624 | 88.5% |

#### 3. 观察

**一，h1 越宽，h1 单层 D_f 越低。** 从 0.645 单调降到 0.060。宽层比窄层保留更多类别信息。

**二，输出层 D_f 几乎不随 h1 宽度变化。** 六种配置下 out D_f 全在 0.61-0.62。这是"输出层锁死"的强验证——锁死与前面的宽度无关，只与输出层自身维度有关。

**三，准确率先升后降。** 512 时最高（89.1%），1024 反而跌到 88.5%。**过宽不再带来收益，甚至略降。**

#### 4. 结论

**h1 宽度影响的是 h1 层自身的 D_f，不影响输出层锁死，也不单调提升准确率。**

**信息在宽层里更"分散"（单层 D_f 低），但最终可用信息受输出层维度上限约束。**

### 8.5 信息迁移：输出层丢失的信息在倒数第二层里

#### 1. 问题

输出层 D_f 被维度锁死。那被锁掉的信息去哪了？

#### 2. 设计

两个互补实验：

**实验一（窄 penult）**：固定输出层为 10 维，扫 penult 维度 2、4、8、16、32。

**实验二（宽 penult）**：对比三种配置 A(64-32-10)、B(64-32-128-10)、C(64-32-512-10)。

测三个量：

- D_f(out)：只看输出层
- D_f(penult)：只看倒数第二层
- D_f(combined)：两层联合

**判据：如果 D_f(combined) < D_f(out)，说明输出层丢的信息在 penult 里，联合能读出来。**

#### 3. 结果

**实验一：窄 penult**

| penult 维度 | 准确率 | D_f(out) | D_f(penult) | D_f(combined) |
| :--- | :--- | :--- | :--- | :--- |
| 2 | 11.0% | 0.996 | 0.996 | 0.996 |
| 4 | 30.0% | 0.746 | 0.806 | 0.767 |
| 8 | 76.9% | 0.650 | 0.754 | **0.642** |
| 16 | 85.1% | 0.617 | 0.633 | **0.528** |
| 32 | 88.0% | 0.626 | 0.521 | **0.448** |

**实验二：宽 penult**

| 配置 | out | out+margin | out+penult | penult |
| :--- | :--- | :--- | :--- | :--- |
| A (64-32-10) | 0.642 | 0.633 | **0.432** | 0.477 |
| B (64-32-128-10) | 0.626 | 0.651 | **0.188** | 0.189 |
| C (64-32-512-10) | 0.623 | 0.610 | **0.100** | 0.101 |

#### 4. 观察

**一，penult 太窄时没有迁移。** penult=2 时全崩（acc 11%，D_f ≈ 1）。penult=4 时 combined（0.767）> out（0.746），也没有迁移。

**二，penult ≥ 8 时迁移出现，且越宽越强。** 
- penult=8：combined 0.642 < out 0.650
- penult=16：combined 0.528 < out 0.617
- penult=32：combined 0.448 < out 0.626

**三，penult 宽到 128 以上时，联合 D_f 主要由 penult 主导。** 
- B 配置：combined（0.188）≈ penult（0.189），输出层贡献很小
- C 配置：combined（0.100）≈ penult（0.101）

**四，A 配置里联合比 penult 自己还好。** 
- A：combined（0.432）< penult（0.477）
- **输出层和倒数第二层是互补的**——输出层贡献了 penult 没有的信息

**五，margin 没有迁移。** out+margin 和 out 几乎一样（0.61-0.65）。margin 是标量，承载不了被锁掉的信息。

#### 5. 结论

**输出层丢的信息，不是消失了，是迁移到了它和倒数第二层的联合分布里。**

**关键不是"信息在别处"，而是"信息在关系里"。**

**信息在输出层和倒数第二层之间是互补的——哪一层更宽，哪一层承担更多。**

#### 8.5.1 迁移的阈值：成比例，不是绝对

##### 1. 问题

信息迁移从什么时候开始？阈值是绝对的维度，还是与类别数成比例？

##### 2. 设计

两个场景：

- **5 类**：penult = 4, 8, 16, 32
- **10 类**：penult = 4, 8, 16, 32

测 gain = D_f(out) − D_f(combined)。**gain > 0 表示迁移发生。**

##### 3. 结果

**5 类：**

| penult | 比例 | 准确率 | D_f_out | D_f_comb | gain |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 4 | 0.8x | 75.8% | 0.584 | 0.530 | **+0.054** |
| 8 | 1.6x | 96.6% | 0.509 | 0.440 | +0.069 |
| 16 | 3.2x | 97.6% | 0.542 | 0.379 | +0.163 |
| 32 | 6.4x | 97.1% | 0.515 | 0.238 | +0.277 |

**10 类：**

| penult | 比例 | 准确率 | D_f_out | D_f_comb | gain |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 4 | 0.4x | 30.0% | 0.749 | 0.751 | **-0.002** |
| 8 | 0.8x | 76.9% | 0.651 | 0.604 | +0.046 |
| 16 | 1.6x | 85.1% | 0.615 | 0.531 | +0.084 |
| 32 | 3.2x | 88.0% | 0.658 | 0.431 | +0.227 |

##### 4. 观察

**一，迁移阈值是成比例的，不是绝对的。**

在同样的 **0.8x 类别数**比例下：
- 5 类（penult=4）的 gain = **+0.054**
- 10 类（penult=8）的 gain = **+0.046**

**两者几乎一样。**

**二，迁移阈值约为 0.8 × 类别数。**

- 10 类在 penult=4（0.4x）时完全没有迁移
- 10 类在 penult=8（0.8x）时开始有微弱迁移
- 5 类在 penult=4（0.8x）时已经开始迁移

**三，gain 随 penult 增大而单调增大。** 两个场景都是：penult 越宽，迁移越强。

##### 5. 结论

**信息迁移的阈值是成比例的：当 penult 的维度达到 0.8 × 类别数时，迁移开始。**

##### 6. 与 9.2 节的关系

**一个漂亮的巧合：**

- 迁移阈值 ≈ **0.8 × 类别数**
- 有效秩 ≈ **1.25 × 类别数**（9.2 节旧版）
- **1 / 1.25 = 0.8**

**这不是巧合：迁移阈值 = 1 / (有效秩 / 类别数)。**

也就是说，**当 penult 的维度达到有效秩的倒数时，迁移开始。**

### 8.6 完整训练曲线：D_f 震荡，margin 单调

#### 1. 设计

在 5 层网络（256-128-64-32-16-10）上训练 40 epoch，每隔 2 epoch 记录：训练 loss、测试准确率、D_f（输出层）、margin（输出层）。

#### 2. 结果

| Epoch | Acc | D_f | Margin |
| :--- | :--- | :--- | :--- |
| 1 | 44.8% | 0.709 | **-0.024** |
| 2 | 72.0% | 0.666 | 0.848 |
| 3 | 80.0% | 0.640 | 1.518 |
| 5 | 85.7% | 0.636 | 2.677 |
| 8 | 89.1% | 0.603 | 3.589 |
| 10 | 88.4% | 0.569 | 4.012 |
| 16 | 93.0% | 0.606 | 5.787 |
| 20 | 92.4% | 0.593 | 6.924 |
| 28 | 92.8% | 0.594 | 9.115 |
| 36 | 92.8% | 0.616 | 10.332 |
| 40 | 93.0% | 0.589 | **10.801** |

#### 3. 观察

**一，D_f 从头到尾在 0.56-0.71 之间震荡。** 从 0.709 到 0.589，几乎没有净趋势。

**二，margin 单调上升。** 从 -0.024 到 10.8。

**三，饱和点分析全部 None。** D_f、margin、准确率三个量，在 40 epoch 内都没找到饱和点。

#### 4. 结论

**D_f 和 margin 的行为完全相反：D_f 震荡，margin 单调。** 这进一步证明：D_f 不能作训练信号，margin 可以。

**同时，三个量都没有饱和点，直接支持 XII 节：D_f 的饱和点不能作早停信号——因为根本没有饱和点。**

## IX. 结果六：关系结构的低秩性、拟合形式、边界与反常

### 9.1 关系是低秩的

| 量 | 值 |
| :--- | :--- |
| 有效秩 | **11.98** |
| 随机矩阵有效秩 | 18.69 |
| 最大特征值间隙 | 20.34 |
| 第一特征值占比 | **32.9%** |
| 前 5 特征值占比 | 63.1% |
| 前 10 特征值占比 | 84.2% |
| 前 20 特征值占比 | 98.7% |

**128 个神经元，但它们的关联结构只有约 12 个有效维度。**

### 9.2 有效秩的形式：训练充分度决定一切

#### 1. 旧版结果（训练不充分）

早期实验训练 10 epoch，准确率 88-97%，测得：

| k（类别数） | 有效秩 r_eff | 准确率 |
| :--- | :--- | :--- |
| 2 | 2.62 | — |
| 3 | 5.28 | 98.7% |
| 4 | 7.24 | 97.5% |
| 5 | 8.35 | 97.5% |
| 6 | 10.28 | 96.5% |
| 8 | 12.23 | 92.9% |
| 10 | 12.35 | 88.3% |

拟合：

- 过原点：r_eff − k = 1.263 · log₂(k)
- 带截距：r_eff − k = 1.048 · log₂(k) + 0.539
- 线性：r_eff = 1.05 · k + 0.54

**r_eff / k 稳定在 1.2-1.3 之间。**

#### 2. 新版结果（充分训练）

重新跑同样实验，训练到准确率 97-99%，测得：

| k（类别数） | 有效秩 r_eff | 准确率 |
| :--- | :--- | :--- |
| 2 | 2.72 | 99.95% |
| 3 | 6.46 | 99.46% |
| 4 | 9.66 | 99.27% |
| 5 | 13.68 | 99.29% |
| 6 | 14.02 | 98.91% |
| 8 | 19.70 | 98.26% |
| 10 | 19.58 | 97.23% |

拟合：

- 过原点：r_eff − k = 3.164 · log₂(k)
- 带截距：r_eff − k = 4.442 · log₂(k) − 3.202
- 线性：r_eff = 2.17 · k + 0.49

**r_eff / k 从 1.36（k=2）升到 2.74（k=5），再降到 1.96（k=10），不是常数。**

#### 3. 两版对比

| k | 旧版 r_eff | 新版 r_eff | 差距 |
| :--- | :--- | :--- | :--- |
| 2 | 2.62 | 2.72 | +0.10 |
| 3 | 5.28 | 6.46 | +1.18 |
| 4 | 7.24 | 9.66 | +2.42 |
| 5 | 8.35 | 13.68 | **+5.33** |
| 6 | 10.28 | 14.02 | +3.74 |
| 8 | 12.23 | 19.70 | **+7.47** |
| 10 | 12.35 | 19.58 | **+7.23** |

**训练越充分，有效秩越高。差距随 k 增大而扩大。**

#### 4. 饱和检查（新版）

```
k: 2 → 3,  Δr_eff/Δk = +3.74
k: 3 → 4,  Δr_eff/Δk = +3.20
k: 4 → 5,  Δr_eff/Δk = +4.02
k: 5 → 6,  Δr_eff/Δk = +0.34   ← 几乎不动
k: 6 → 8,  Δr_eff/Δk = +2.84   ← 又跳起来
k: 8 → 10, Δr_eff/Δk = -0.06   ← 变成负的
```

**不是单调增长，不是平滑饱和，是抖动的。**

#### 5. 结论

**有效秩不是单一公式能刻画的。它是"任务需求 + 训练充分度 + 架构能力"三者共同决定的。**

- **旧版**（训练 10 epoch）：受训练不足压制，r_eff ≈ 1.25 × k
- **新版**（训练充分）：r_eff 更高，但不服从简单公式，且在高 k 处抖动

**"有效秩 ≈ 1.25 × 类别数"是一个"训练不充分"下的经验关系，不是普遍规律。**

### 9.3 背景模式是架构驱动的（直接投影层）

| 模式 | 特征值 | MI(类别) | 亮度 | 对比度 | 边缘密度 | 高频占比 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 0（背景） | 22.82 | 0.434 | **-0.941** | **-0.942** | -0.427 | 0.748 |
| 1 | 6.88 | 0.831 | -0.240 | -0.215 | -0.061 | 0.229 |
| 2 | 6.50 | 0.933 | -0.007 | -0.010 | -0.291 | -0.159 |
| 3 | 5.03 | 0.826 | -0.474 | -0.434 | -0.535 | 0.205 |
| 4 | 4.63 | 0.621 | 0.223 | 0.207 | 0.345 | -0.026 |

**五个观察：**

**一，背景模式只编码全局统计量。** 模式 0 与亮度/对比度相关性 -0.94，与高频占比 0.75，但与类别 MI 只有 0.43。

**二，类别模式不碰全局统计量。** 模式 1、2、3 的 MI 都在 0.83 以上，但与亮度/对比度相关性全部低于 0.48。

**三，亮度与对比度不可分。** 在 MNIST 里，这两个统计量本身高度共线（-0.941 vs -0.942），无法区分背景模式编码的是哪一个。

**四，边缘密度和高频占比不是背景模式的主成分。** 背景模式不是"复杂度"，是"全局能量"。

**五，2 类任务的背景模式 MI = 0.775，10 类任务 MI = 0.432。** 背景模式不随任务变，是架构的属性。

### 9.4 边界：分离结构只在直接投影层成立

#### 1. 问题

"背景 + 类别"的分离结构，是普遍的，还是只在特定架构下成立？

#### 2. 设计

三个系统对比：MNIST + FC、CIFAR-10 + FC、CIFAR-10 + CNN。

#### 3. 结果

| 量 | MNIST (FC) | CIFAR (FC) | CIFAR (CNN) |
| :--- | :--- | :--- | :--- |
| 准确率 | 88.3% | 36.6% | 69.0% |
| 有效秩 | 12.30 | 11.96 | **4.78** |
| 背景模式 MI | 0.433 | 0.205 | 0.183 |
| 背景 vs 亮度 | -0.941 | -0.863 | **-0.076** |
| 背景 vs 对比度 | -0.942 | -0.359 | **-0.498** |

#### 4. 观察

**一，有效秩大幅下降：12 → 4.78。**

**二，背景模式不再编码亮度。** MNIST：-0.941；CIFAR-CNN：-0.076（几乎无关）。

**三，类别信息更分散。**

#### 5. 结论

**"背景 + 类别"的分离结构，不是普遍的。它只在"直接投影层"成立。**

#### 6. 意义

> **"背景 + 类别"分离出现在"输入的第一次投影"。卷积之后的层，结构不同。**

这对应全息原理中的一个细节：**"边界"必须是"最外层"。**

### 9.5 高类别数下的反常：有效秩饱和

#### 1. 结果

| 类别数 | 有效秩 | 准确率 |
| :--- | :--- | :--- |
| 5 | 8.43 | 97.5% |
| 10 | 12.00 | 88.3% |
| **20** | **8.73** | **85.3%** |

**20 类的有效秩（8.73）低于 10 类（12.00）。**

#### 2. 长训练对照

| Epoch | 准确率 | 有效秩 |
| :--- | :--- | :--- |
| 5 | 81.5% | 8.39 |
| 10 | 85.1% | 8.77 |
| 20 | 86.4% | 9.17 |
| 30 | 88.1% | **10.01** |

**20 类的有效秩随训练持续上升，30 epoch 仍未饱和。**

#### 3. 结论

**有效秩是"任务需求 + 架构能力 + 训练充分度"三者共同决定的。** 高类别数下，有效秩会在某个水平上饱和。

## XI. 与黑洞的对应

### 1. AdS/CFT 的量子纠错码

2015 年，Almheiri、Dong、Harlow 提出：AdS/CFT 对偶本质上是一个量子纠错码。

### 2. 黑洞信息悖论的岛屿机制

2019 年，Penington、Almheiri 等人用 QECC 框架解决黑洞信息悖论：信息不在单个辐射量子中，而在辐射之间的量子纠缠里。

### 3. 本文的对应

| | AdS/CFT | 神经网络 |
| :--- | :--- | :--- |
| 体内信息 | 黑洞内部 | 类别标签 |
| 边界自由度 | CFT 量子比特 | h1 神经元 |
| 编码方式 | 量子纠错码 | 关联纠错码 |
| 损坏容忍 | 部分边界比特可损 | 部分神经元可打乱 |
| 崩溃阈值 | ~50% | ~40-60% |
| 大系统更鲁棒 | 大黑洞更耐损 | 宽层更耐损 |
| 编码出现时机 | 视界形成时 | 第一个 epoch 内 |
| 关系结构 | 纠缠谱 | 低秩互信息矩阵 |
| 有效维度 | 全息自由度 | 受训练充分度与架构共同决定 |
| 背景模式 | 视界几何 | 亮度/对比度（与类别无关） |
| 类别模式 | 落入物质的信息 | 中等特征模式（与类别强相关） |
| 背景/类别分离 | 几何/物质分离 | 只在直接投影层成立 |
| 信息在关联里（全息） | 边界自由度之间的纠缠 | 每层神经元之间的关联 |
| 信息在联合里（岛屿） | 辐射 + 内部纠缠 | out + penult 联合 |
| 信息迁移阈值 | 与内部自由度成比例 | 0.8 × 类别数 |
| 高能标饱和 | 高维视界退化 | 高类别数有效秩饱和 |

### 4. 三个精确对应点

**一，纠错码结构与"信息在关联里"是同一件事的两面。**

**二，背景模式与类别模式的分离，只在最外层投影成立。** 这对应"边界必须是最外层"。

**三，有效秩的次线性增长与饱和，对应全息屏上的自由度上限。**

**四，信息迁移对应岛屿机制。** 输出层丢的信息，在它和倒数第二层的联合里——就像霍金辐射的信息，在辐射和内部的联合纠缠里。

## XII. 一个被证伪的假设

### 1. 假设

D_f 的饱和点可以作早停信号。

### 2. 结果

D_f 的震荡幅度（±0.03-0.05）大于"饱和信号"。三个配置中，两个"未饱和"，一个"饱和"但被噪声干扰。

### 3. 结论

**D_f 作早停信号的假设不成立。**

### 4. 补充：40 epoch 完整训练中，三个量都没有饱和点

8.6 节的完整训练曲线显示：在 40 epoch 内，D_f、margin、准确率三个量**都没有出现饱和点**。

- D_f 从头到尾在 0.56-0.71 之间震荡
- margin 单调上升，没有平缓
- 准确率在 90% 附近波动，没有收敛

**所以"D_f 饱和点"本身不存在。**

## XIII. 局限

1. **单一数据集（部分）**：大部分实验在 MNIST 上，CIFAR 只用于边界测试，未在 ImageNet 验证。
2. **单一架构（部分）**：以全连接网络为主，CNN 只用于 9.4 节的边界测试，未系统比较 Transformer。
3. **D_f 估计噪声**：用分类器交叉熵估计，有固有噪声。
4. **打乱操作的局限**：未系统比较擦除、噪声等其他损坏方式。
5. **阈值定位粗略**：h1=512 的阈值定位在 0.6-0.8 之间。
6. **与 QECC 的对应是结构性的**：不是物理等价。
7. **互信息估计的分箱依赖**：互信息矩阵用 10 个 bin 估计，可能有离散化误差。
8. **有效秩的拟合区间有限**：旧版拟合只在 k ≤ 10 且训练不充分时成立。充分训练版数据不支持简单公式。
9. **图像统计量的选择**：只测了 4 个统计量，可能有遗漏。
10. **20 类未充分训练**：20 类长训练到 30 epoch 仍未饱和，有效秩的稳态值未知。
11. **训练充分度未系统扫描**：只比较了"10 epoch"和"充分训练"两档。
12. **迁移阈值的精度**：0.8 × 类别数 只有两个类别数的数据点，更精确的比例需要更多类别数验证。

## XIV. 结论

### 1. 核心结果

**第一，信息主要分布在神经元之间的关联里，不集中在少数神经元。** 对 h1=128，75% 的信息在关联里。按方差排序逐步加入神经元，D_f 从 1.000 缓慢降到 0.355，与随机排序几乎相同——方差挑不出"重要神经元"。

**第二，部分打乱曲线呈凸形，表明存在纠错码结构。**

**第三，纠错阈值随层宽度增强。**

**第四，纠错码在训练的第一个 epoch 内被激活，并整体提升信息保留。** 训练后每层 D_f 大幅下降（layer1 从 0.472 降到 0.256，output 从 0.777 降到 0.389），输入层不变。

**第五，输出层 D_f 被维度锁死。** 输出熵和 margin 才是准确率的强预测子（相关系数 -0.99 和 +0.98）。D_f 与准确率相关系数只有 -0.52。

**第六，关系是低秩的，有效秩随类别数增长，但形式取决于训练充分度。** 训练不充分时 r_eff ≈ 1.25 × 类别数；训练充分后有效秩更高但不服从简单公式。

**第七，在全连接网络的直接投影层，"背景模式"是架构驱动的。** 最大的特征模式与类别无关，不随任务变，编码输入的全局统计量。

**第八，背景模式与类别模式的分离，只在"直接投影层"成立。** 对 CIFAR-CNN，有效秩降至 4.78，背景模式与亮度几乎无关。

**第九，有效秩在高类别数和充分训练下出现饱和。** 20 类的有效秩（8.73）低于 10 类（12.00）。

**第十，信息迁移阈值约为 0.8 × 类别数。** 输出层丢的信息，在它与倒数第二层的联合里。

### 2. 与黑洞的对应

这些结果定量对应 AdS/CFT 对偶中的量子纠错码图景，以及黑洞信息悖论的岛屿机制。

### 3. 本文的定位

**本文不是一个新物理发现，而是一个定量的跨系统对应。**

它给出八个之前未被报告的数：

- 纠错阈值随层宽度线性增强
- 纠错码在第一个 epoch 内被激活
- 有效秩受训练充分度强烈影响（同任务下差 7 个单位）
- 迁移阈值 ≈ 0.8 × 类别数
- 背景模式与类别模式的分离
- 背景模式 = 直接投影层的输入全局统计量
- 有效秩在 20 类下饱和
- 逐层关联贡献占比 52-75%

### 4. 三个更深的问题

**一，背景模式编码的是"输入的全局统计量"。类别模式编码的是"任务需要的区分"。这个"背景 + 信号"的分离，是不是所有信息处理系统的普遍结构？**

**二，"分离只在直接投影层成立"意味着什么？** 卷积之后的层，是不是丢失了某种"边界"属性？

**三，有效秩的饱和意味着什么？** 高类别数下 h1 层的维度是不是一个"物理上限"？
